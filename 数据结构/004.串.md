## 1 概述

### 1.1 串的定义

串（String，字符串）是由零个或多个字符组成的有限序列，记作：

```text
S = "a1 a2 a3 ... an"    (n >= 0)
```

其中 `S` 是串名，双引号内的字符序列是串值，`n` 是串的长度。串的逻辑结构仍是线性结构，只是每个数据元素限定为一个字符。

### 1.2 基本术语

| 术语 | 含义 |
| --- | --- |
| 空串 | 长度为 0 的串，记作 `""` |
| 空格串 | 由一个或多个空格组成的串，长度等于空格个数，不是空串 |
| 子串 | 串中任意个连续字符组成的子序列 |
| 主串 | 包含子串的串 |
| 真子串 | 不包含自身的子串 |
| 字符位置 | 字符在串中的序号，通常从 1 开始 |
| 子串位置 | 子串第一个字符在主串中的位置 |
| 串相等 | 两个串长度相同，且对应位置字符全部相同 |

例如 `T = "aba"` 是 `S = "ababa"` 的子串，`T` 在 `S` 中第一次出现的位置是 1；`"ab"`、`"ba"` 也都是 `S` 的真子串，而 `"aa"` 不是 `S` 的子串，因为字符不连续。

### 1.3 基本操作

* `StrAssign(S, T)`：赋值，把串 `T` 的值赋给 `S`。
* `StrCopy(S, T)`：复制。
* `StrCompare(S, T)`：比较，按字典序返回负、零、正。
* `StrLength(S)`：求串长。
* `Concat(S, T1, T2)`：连接。
* `SubString(Sub, S, pos, len)`：求从 `pos` 开始的 `len` 个字符组成的子串。
* `Index(S, T, pos)`：从 `pos` 起在主串 `S` 中查找子串 `T`，返回首次出现的位置。

408 中最重要的操作是**定位（模式匹配）**：在主串 `S` 中查找模式串 `T`。

## 2 存储结构

| 存储方式 | 具体做法 | 优点 | 缺点 |
| --- | --- | --- | --- |
| 定长顺序存储 | 用定长字符数组存放，另设长度或使用 `'\0'` 结尾 | 随机访问、实现简单 | 长度固定，超出会截断 |
| 堆分配存储 | 用 `malloc` 在堆区申请连续空间，长度可动态变化 | 长度灵活，仍可随机访问 | 需要手动管理内存，扩容要复制 |
| 块链存储 | 每个结点存放一个或多个字符，用指针连接 | 插入、删除方便，长度动态 | 存储密度低，随机访问需遍历 |

定长顺序串一般有两种表示：一种在 `0` 号单元存放串长，字符从 `1` 号单元开始；另一种用 `'\0'` 作为结束标志。后者是 C 语言字符串的表示方式，求长度需要扫描整个串，时间复杂度为 $O(n)$。

块链存储中，若一个结点存放多个字符，最后一个结点往往存不满，通常用特殊字符（如 `#`）填充，这些填充字符**不计入串长**。

## 3 基本操作与实现

### 3.1 朴素模式匹配

朴素算法（BF，Brute Force）从主串的每个位置开始，逐字符与模式串比较；一旦失配，主串指针回退到本次起点的下一个位置，模式串指针回到开头。

```c
// 返回模式串 t 在主串 s 中第一次出现的位置（1 开始），不存在返回 0
int IndexBF(const char *s, const char *t) {
    int i = 0, j = 0;
    while (s[i] != '\0' && t[j] != '\0') {
        if (s[i] == t[j]) {
            i++;
            j++;
        } else {
            i = i - j + 1;   // 主串回到本次起点的下一个位置
            j = 0;           // 模式串从头开始
        }
    }
    if (t[j] == '\0') return i - j + 1;
    return 0;
}
```

最坏情况下，主串和模式串形如 `"000...000"` 与 `"000...001"`，每趟都要比较到模式串末尾才失配，时间复杂度为 $O(nm)$，其中 $n$、$m$ 分别是主串和模式串长度。

### 3.2 KMP 算法与 next 数组

BF 的问题在于：失配后主串指针要回退，之前已经比较过的信息被浪费。KMP 利用模式串自身的结构，让**主串指针不回退**，只移动模式串指针。

#### 3.2.1 最长相等前后缀

对模式串 `P` 的前缀 `P[1..j-1]`：

* 前缀：从 `P[1]` 开始的一段连续字符，长度小于 `j-1`。
* 后缀：以 `P[j-1]` 结尾的一段连续字符，长度小于 `j-1`。
* 最长相等真前后缀长度记作 `L`，即最长的、既是前缀又是后缀且不等于整个前缀的字符串长度。

例如 `P[1..5] = "abaab"`，真前缀有 `"a"`、`"ab"`、`"aba"`、`"abaa"`，真后缀有 `"b"`、`"ab"`、`"aab"`、`"baab"`，其中相等且最长的是 `"ab"`，所以 `L = 2`。

#### 3.2.2 next 数组的定义

本笔记采用 408 教材常用的 **1 起始**约定，`P[1..m]` 为模式串：

```text
next[1] = 0
next[j] = P[1..j-1] 的最长相等真前后缀长度 + 1    (j > 1)
```

因此 `j > 1` 时，`next[j] - 1` 就是失配位置之前那段字符的最长相等真前后缀长度。失配时令 `j = next[j]`，相当于把模式串向右滑动，使相等的前缀对准原来的后缀，继续比较。

> 若采用 0 起始的代码实现，通常写成 `next[0] = -1`，其余值为“最长相等前后缀长度”。两种约定本质相同，考试答题时要看清题目要求的下标起点。

#### 3.2.3 递推求 next

已知 `next[j] = k`，即 `P[1..k-1] = P[j-k+1..j-1]`。现在求 `next[j+1]`：

* 若 `P[j] == P[k]`，则在原相等前后缀后各延长一个字符，仍有 `P[1..k] = P[j-k+1..j]`，所以 `next[j+1] = k + 1`。
* 若 `P[j] != P[k]`，说明长度为 `k` 的候选失败，令 `k = next[k]`，退而寻找更短的前缀继续比较。
* 当 `k` 退到 0 时，说明没有非空相等前后缀，`next[j+1] = 1`。

`next[1] = 0` 是人为设置的哨兵：当模式串第一个字符就失配时，令 `j = 0`，下一轮主串指针后移、模式串从 1 重新开始。

#### 3.2.4 手算例子

以 `P = "abaabcac"` 为例，先求每个位置之前的最长相等真前后缀长度 `L`，再令 `next[j] = L + 1`（`j > 1`）：

| `j` | `P[j]` | 前缀 `P[1..j-1]` | 最长相等真前后缀 | `L` | `next[j]` |
| --- | --- | --- | --- | --- | --- |
| 1 | a | 空 | 无 | — | 0 |
| 2 | b | `"a"` | 无 | 0 | 1 |
| 3 | a | `"ab"` | 无 | 0 | 1 |
| 4 | a | `"aba"` | `"a"` | 1 | 2 |
| 5 | b | `"abaa"` | `"a"` | 1 | 2 |
| 6 | c | `"abaab"` | `"ab"` | 2 | 3 |
| 7 | a | `"abaabc"` | 无 | 0 | 1 |
| 8 | c | `"abaabca"` | `"a"` | 1 | 2 |

所以 `next = [0, 1, 1, 2, 2, 3, 1, 2]`（下标从 1 开始）。

用这个模式串匹配主串 `S = "abaabaabcac"`：前 5 个字符 `"abaab"` 匹配，到 `S[6] = 'a'` 与 `P[6] = 'c'` 失配，此时 `j = next[6] = 3`，表示 `P[1..2] = "ab"` 已经和 `S[4..5]` 对齐，直接从 `S[6]` 与 `P[3]` 继续比较即可，主串指针不需要回退。

#### 3.2.5 求 next 的代码

```c
void GetNext(const char *p, int next[]) {
    int m = (int)strlen(p + 1);   // p[1..m] 存放模式串
    int i = 1, j = 0;
    next[1] = 0;
    while (i <= m) {
        if (j == 0 || p[i] == p[j]) {
            i++;
            j++;
            next[i] = j;
        } else {
            j = next[j];
        }
    }
}
```

循环中 `j` 始终表示当前候选的 `next` 值。`j == 0` 时不再回退，直接令 `next[i+1] = 1`，这就是哨兵的作用。

### 3.3 完整可运行的 KMP 程序

```c
#include <stdio.h>
#include <string.h>

#define MAXN 1000

char s[MAXN + 2], p[MAXN + 2];   // 从下标 1 开始存放
int nxt[MAXN + 2];

void GetNext(const char *p, int next[]) {
    int m = (int)strlen(p + 1);
    int i = 1, j = 0;
    next[1] = 0;
    while (i <= m) {
        if (j == 0 || p[i] == p[j]) {
            i++;
            j++;
            next[i] = j;
        } else {
            j = next[j];
        }
    }
}

// 返回首次匹配的起始位置（1 开始），失败返回 0
int IndexKMP(const char *s, const char *p, const int next[]) {
    int i = 1, j = 1;
    int n = (int)strlen(s + 1);
    int m = (int)strlen(p + 1);
    while (i <= n && j <= m) {
        if (j == 0 || s[i] == p[j]) {
            i++;
            j++;
        } else {
            j = next[j];       // 主串指针 i 不回退
        }
    }
    if (j > m) return i - m;
    return 0;
}

int main(void) {
    if (scanf("%1000s%1000s", s + 1, p + 1) != 2) return 0;
    GetNext(p, nxt);
    printf("%d\n", IndexKMP(s, p, nxt));
    return 0;
}
```

例如输入 `abaabaabcac abaabcac`，输出 `4`，表示模式串第一次出现在主串第 4 个字符处。

### 3.4 nextval 优化

如果 `P[j] == P[next[j]]`，那么在第 `j` 个字符失配后回退到 `next[j]`，仍然会与同一个主串字符失配，这次回退没有意义。`nextval` 把这种回退继续“压缩”：

```text
nextval[1] = 0
若 P[j] == P[next[j]]，则 nextval[j] = nextval[next[j]]
否则 nextval[j] = next[j]
```

对 `P = "abaabcac"`：

| `j` | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| `P[j]` | a | b | a | a | b | c | a | c |
| `next[j]` | 0 | 1 | 1 | 2 | 2 | 3 | 1 | 2 |
| `nextval[j]` | 0 | 1 | 0 | 2 | 1 | 3 | 0 | 2 |

例如 `j = 3` 时，`P[3] = 'a'`，`P[next[3]] = P[1] = 'a'`，两者相同，所以 `nextval[3] = nextval[1] = 0`；而 `j = 4` 时，`P[4] = 'a'`，`P[next[4]] = P[2] = 'b'`，不同，所以 `nextval[4] = next[4] = 2`。

```c
void GetNextval(const char *p, const int next[], int nextval[]) {
    int m = (int)strlen(p + 1);
    nextval[1] = 0;
    for (int j = 2; j <= m; j++) {
        if (p[j] == p[next[j]])
            nextval[j] = nextval[next[j]];
        else
            nextval[j] = next[j];
    }
}
```

使用 `nextval` 时，匹配函数中的回退语句改为 `j = nextval[j];` 即可。`nextval` 不改变最坏时间复杂度，但通常能减少实际比较次数。

## 4 复杂度与特性对比

| 算法 | 最好情况 | 最坏情况 | 平均情况 | 空间 |
| --- | --- | --- | --- | --- |
| 朴素模式匹配 | $O(n)$ | $O(nm)$ | 接近 $O(n+m)$ | $O(1)$ |
| KMP | $O(n+m)$ | $O(n+m)$ | $O(n+m)$ | $O(m)$ |
| KMP + nextval | $O(n+m)$ | $O(n+m)$ | $O(n+m)$，常数更小 | $O(m)$ |

| 存储结构 | 随机访问 | 插入/删除 | 空间特点 |
| --- | --- | --- | --- |
| 定长顺序串 | $O(1)$ | $O(n)$ | 可能有截断或浪费 |
| 堆分配串 | $O(1)$ | $O(n)$ | 按需分配，可能碎片化 |
| 块链串 | $O(n)$ | 定位后 $O(1)$ | 指针占空间，存储密度低 |

## 5 典型应用

* 文本编辑器、IDE 的查找功能，以及 `grep` 等工具的子串搜索。
* 编译器的词法分析：识别关键字、标识符等模式。
* 生物信息学中的 DNA/蛋白质序列匹配，KMP 的思想也是多模式匹配自动机的基础。
* 利用 `next` 数组求字符串的周期：若 `next[n] - 1` 是前缀 `P[1..n]` 的最长相等真前后缀长度，则最小周期为 `p = n - (next[n] - 1)`。当 `n % p == 0` 时，`p` 就是最小循环节长度；否则说明末尾不足一个完整循环节。
* `nextval` 用于减少失配后的无效比较，是 KMP 的常见工程优化。

## 6 常考题型与小结

* 手算 `next`、`nextval`：先找“失配位置之前”的最长相等真前后缀长度，再按定义加 1；注意下标从 0 还是从 1 开始。
* 给出主串和模式串，写出 KMP 的匹配过程，包括每次失配后 `j` 的变化。
* 比较 BF 与 KMP 的时间复杂度，说明 KMP 为什么能做到主串指针不回退。
* 判断空串与空格串、子串与真子串、子串位置等概念。
* 设计字符串相关算法：删除指定字符、求子串、判断回文、统计子串出现次数等，通常先考虑顺序存储。

小结：串的核心是模式匹配。BF 思路直观但会回退主串；KMP 通过 `next` 数组记录模式串的“自相似”信息，把匹配时间降到 $O(n+m)$。真正理解 `next[j]` 的含义——失配后模式串应跳到的位置——比死记代码更重要。
