## 1 概述

排序是把一组记录按关键字递增或递减排列的操作。排序算法通常从三个方面评价：

- **时间复杂度**：最好、平均、最坏情况下的比较次数和移动次数。
- **空间复杂度**：除输入数组外额外使用的辅助空间。
- **稳定性**：若两个记录关键字相等，排序前后它们的相对次序不变，则算法稳定；否则不稳定。

按存储介质分为内部排序（数据在内存）和外部排序（数据太大，需要访问外存）。按是否比较关键字分为比较类排序（插入、交换、选择、归并）和非比较类排序（基数排序）。基于比较的排序在最坏情况下至少需要 $\Omega(n\log n)$ 次比较。

## 2 核心内容

### 2.1 插入类排序

**直接插入排序**：把第一个元素看成有序区，依次取出后面每个元素，在有序区中从后向前比较并后移，找到位置后插入。已经有序时只需比较不移动，最好 $O(n)$；逆序时最坏 $O(n^2)$，平均 $O(n^2)$；空间 $O(1)$；相等元素不越过，**稳定**。适合小规模或基本有序的数据。

**希尔排序**：按下标增量 `gap` 把序列分成若干子序列，对每个子序列做直接插入排序；增量逐步缩小，最后 `gap=1` 时整体再插入排序。前期让元素大步靠近目标位置，后期工作量减小。时间复杂度依赖增量序列，常用 `n/2, n/4, ...` 时最坏 $O(n^2)$，平均约 $O(n^{1.3})$；空间 $O(1)$；**不稳定**。

### 2.2 交换类排序

**冒泡排序**：相邻元素两两比较，逆序则交换。每一趟把当前未排序部分的最小（或最大）元素送到一端；若某趟没有交换，说明已经有序，可提前结束。最好 $O(n)$，最坏和平均 $O(n^2)$，空间 $O(1)$，**稳定**。

**快速排序**：选一个枢轴（pivot），通过一趟划分把小于等于枢轴的放左边、大于等于的放右边，枢轴落到最终位置，再递归处理左右子区间。平均 $O(n\log n)$，最坏 $O(n^2)$（如已有序且总取首元素为枢轴）；递归栈平均 $O(\log n)$，最坏 $O(n)$；**不稳定**。随机选枢轴或三数取中可降低最坏情况概率。

### 2.3 选择类排序

**简单选择排序**：每趟从未排序区选出最小元素，与未排序区第一个元素交换。无论初始状态如何都要比较 $n(n-1)/2$ 次，时间恒为 $O(n^2)$，空间 $O(1)$，**不稳定**（交换可能把相等元素的相对次序打乱）。优点是移动次数少。

**堆排序**：把数组看成一棵完全二叉树，下标 `i` 的左右孩子为 `2i+1`、`2i+2`。升序排序使用大根堆：

1. **建堆**：从最后一个非叶结点 `n/2-1` 开始，依次向前对每个结点执行“向下调整”，使父结点不小于孩子。建堆总时间 $O(n)$。
2. **调整**：每次交换堆顶与当前末尾元素，堆长度减一，再对堆顶向下调整，恢复大根堆。
3. 重复 $n-1$ 次，末尾依次形成有序的最大元素。

向下调整时，把当前结点与较大的孩子比较，若孩子更大就交换并继续向下，直到叶子或满足堆性质。堆的插入把新元素放到末尾，再不断与父结点比较、向上调整；删除堆顶时用末尾元素覆盖根，再向下调整。堆排序时间恒为 $O(n\log n)$，空间 $O(1)$，**不稳定**。堆还支持 $O(\log n)$ 的插入和删除堆顶，适合优先队列和 Top-K。

例如对 `[4,1,3,2,6,5]` 建大根堆：从下标 2 开始，`3` 与孩子 `5` 交换；再调整下标 1，`1` 与较大的孩子 `6` 交换；最后调整下标 0，`4` 与 `6` 交换，得到 `[6,4,5,2,1,3]`。

### 2.4 归并排序

把序列不断二分，直到每个子序列只有一个元素，再把这些有序子序列两两合并。合并时用双指针比较，谁小取谁；相等时优先取左边元素可保持稳定。归并排序最好、平均、最坏均为 $O(n\log n)$，需要 $O(n)$ 辅助数组，**稳定**。它适合链表排序和外排序；外排序通常先产生若干有序归并段，再多路归并。

### 2.5 基数排序

基数排序不比较关键字大小，而是按关键字的每一位分配和收集。最低位优先（LSD）从个位开始，依次对十位、百位……做**稳定**的分配与收集；处理完最高位后整体有序。若关键字有 $d$ 位、每位取值 $0\sim r-1$，时间 $O(d(n+r))$，空间 $O(n+r)$，**稳定**。它适合位数固定、范围较小的整数或字符串；负数需要先偏移，浮点数不能直接按位排序。

### 2.6 一趟排序结果的判断

考试常给“某趟排序后的结果”，判断所用算法。先看**已经落到最终位置的元素在哪儿**：

- 直接插入：前部是相对有序的已插入序列，但通常还不是全局最终位置；后缀基本未动。
- 冒泡（小元素向前冒）：前 $k$ 个是全局最小的 $k$ 个且有序；若大元素向后冒，则后 $k$ 个是全局最大的。
- 简单选择：前 $k$ 个是全局最小的 $k$ 个且有序。
- 快速排序：枢轴已在最终位置，且左半区都不大于它、右半区都不小于它。
- 堆排序：建堆后数组满足大根堆；每趟把当前最大值放到末尾，末尾逐渐形成有序区。
- 归并排序：自底向上做一趟后，相邻长度为 $2^t$ 的归并段分别有序，整体未必有序。
- 希尔排序：相隔某个增量的子序列分别有序，整体未必有序。
- 基数排序：按最低若干位稳定排序，不能据此判断高位。

## 3 算法与代码

以下均为 C 语言实现，默认对整型数组做升序排序，数组下标从 0 开始。

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

void swap(int *a, int *b) {
    int t = *a; *a = *b; *b = t;
}
```

### 3.1 直接插入排序

```c
void insertionSort(int a[], int n) {
    for (int i = 1; i < n; i++) {
        int key = a[i], j = i - 1;
        while (j >= 0 && a[j] > key) {   // 大于才后移，保证稳定
            a[j + 1] = a[j];
            j--;
        }
        a[j + 1] = key;
    }
}
```

### 3.2 希尔排序

```c
void shellSort(int a[], int n) {
    for (int gap = n / 2; gap > 0; gap /= 2) {
        for (int i = gap; i < n; i++) {
            int key = a[i], j = i - gap;
            while (j >= 0 && a[j] > key) {
                a[j + gap] = a[j];
                j -= gap;
            }
            a[j + gap] = key;
        }
    }
}
```

### 3.3 冒泡排序

```c
void bubbleSort(int a[], int n) {
    for (int i = 0; i < n - 1; i++) {
        int swapped = 0;
        for (int j = n - 1; j > i; j--) {
            if (a[j - 1] > a[j]) {
                swap(&a[j - 1], &a[j]);
                swapped = 1;
            }
        }
        if (!swapped) break;             // 本趟无交换，已经有序
    }
}
```

### 3.4 快速排序

```c
int partition(int a[], int low, int high) {
    int pivot = a[low];
    while (low < high) {
        while (low < high && a[high] >= pivot) high--;
        a[low] = a[high];
        while (low < high && a[low] <= pivot) low++;
        a[high] = a[low];
    }
    a[low] = pivot;
    return low;
}

void quickSort(int a[], int low, int high) {
    if (low < high) {
        int p = partition(a, low, high);
        quickSort(a, low, p - 1);
        quickSort(a, p + 1, high);
    }
}
```

### 3.5 简单选择排序

```c
void selectionSort(int a[], int n) {
    for (int i = 0; i < n - 1; i++) {
        int min = i;
        for (int j = i + 1; j < n; j++)
            if (a[j] < a[min]) min = j;
        if (min != i) swap(&a[i], &a[min]);
    }
}
```

### 3.6 堆排序

```c
void siftDown(int a[], int n, int i) {
    while (1) {
        int largest = i, l = 2 * i + 1, r = 2 * i + 2;
        if (l < n && a[l] > a[largest]) largest = l;
        if (r < n && a[r] > a[largest]) largest = r;
        if (largest == i) break;
        swap(&a[i], &a[largest]);
        i = largest;
    }
}

void heapSort(int a[], int n) {
    for (int i = n / 2 - 1; i >= 0; i--)  // 自底向上建大根堆
        siftDown(a, n, i);
    for (int end = n - 1; end > 0; end--) {
        swap(&a[0], &a[end]);             // 最大值归位
        siftDown(a, end, 0);
    }
}
```

### 3.7 归并排序

```c
void merge(int a[], int tmp[], int left, int mid, int right) {
    int i = left, j = mid + 1, k = left;
    while (i <= mid && j <= right)
        tmp[k++] = (a[i] <= a[j]) ? a[i++] : a[j++]; // 取等号左侧，稳定
    while (i <= mid) tmp[k++] = a[i++];
    while (j <= right) tmp[k++] = a[j++];
    for (i = left; i <= right; i++) a[i] = tmp[i];
}

void mergeSort(int a[], int tmp[], int left, int right) {
    if (left >= right) return;
    int mid = left + (right - left) / 2;
    mergeSort(a, tmp, left, mid);
    mergeSort(a, tmp, mid + 1, right);
    merge(a, tmp, left, mid, right);
}

void mergeSortWrapper(int a[], int n) {
    int *tmp = (int *)malloc(n * sizeof(int));
    if (tmp == NULL) return;
    mergeSort(a, tmp, 0, n - 1);
    free(tmp);
}
```

### 3.8 基数排序

```c
void radixSort(int a[], int n) {
    if (n <= 1) return;
    int max = a[0];
    for (int i = 1; i < n; i++)
        if (a[i] > max) max = a[i];
    int *tmp = (int *)malloc(n * sizeof(int));
    if (tmp == NULL) return;

    for (int exp = 1; max / exp > 0; exp *= 10) {
        int cnt[10] = {0};
        for (int i = 0; i < n; i++)
            cnt[(a[i] / exp) % 10]++;
        for (int i = 1; i < 10; i++)
            cnt[i] += cnt[i - 1];
        for (int i = n - 1; i >= 0; i--) { // 逆序回填，保证稳定性
            int d = (a[i] / exp) % 10;
            tmp[--cnt[d]] = a[i];
        }
        memcpy(a, tmp, n * sizeof(int));
        if (max / exp < 10) break;         // 已处理最高位，防止 exp 溢出
    }
    free(tmp);
}
```

## 4 复杂度/性能对比

| 排序方法 | 最好时间 | 平均时间 | 最坏时间 | 辅助空间 | 稳定性 | 适用场景 |
| --- | --- | --- | --- | --- | --- | --- |
| 直接插入 | $O(n)$ | $O(n^2)$ | $O(n^2)$ | $O(1)$ | 稳定 | 小规模、基本有序 |
| 希尔排序 | 依赖增量 | 约 $O(n^{1.3})$ | $O(n^2)$ | $O(1)$ | 不稳定 | 中等规模、内存受限 |
| 冒泡排序 | $O(n)$ | $O(n^2)$ | $O(n^2)$ | $O(1)$ | 稳定 | 教学、基本有序 |
| 快速排序 | $O(n\log n)$ | $O(n\log n)$ | $O(n^2)$ | $O(\log n)\sim O(n)$ | 不稳定 | 通用内部排序 |
| 简单选择 | $O(n^2)$ | $O(n^2)$ | $O(n^2)$ | $O(1)$ | 不稳定 | 交换代价高、规模小 |
| 堆排序 | $O(n\log n)$ | $O(n\log n)$ | $O(n\log n)$ | $O(1)$ | 不稳定 | Top-K、优先队列 |
| 归并排序 | $O(n\log n)$ | $O(n\log n)$ | $O(n\log n)$ | $O(n)$ | 稳定 | 链表、外排序、稳定需求 |
| 基数排序 | $O(d(n+r))$ | $O(d(n+r))$ | $O(d(n+r))$ | $O(n+r)$ | 稳定 | 定长整数、字符串 |

**补充**：希尔排序的复杂度与增量序列有关，表中给出常见直观结论；基数排序中 $d$ 为位数、$r$ 为基数，十进制时 $r=10$。快速排序的递归栈空间平均 $O(\log n)$，最坏 $O(n)$。

## 5 典型应用与常考题型

**典型应用**：插入排序用于小数组和近乎有序数据；快速排序是通用内存排序的常用选择；归并排序用于链表、需要稳定性的场景和外部排序；堆排序用于优先队列、Top-K 和实时取最大值；基数排序用于固定位数的整数、学号、身份证号等；简单选择排序在交换成本高时仍有价值。

**常考题型**：

1. 给出某一趟排序结果，判断算法或写出下一趟；重点看前缀/后缀是否已到最终位置、枢轴位置、归并段长度。
2. 手工执行快速排序的一趟划分，写出枢轴最终位置和左右子区间；分析有序输入下的最坏情况。
3. 根据序列建大根堆/小根堆，画出每一步调整；完成堆排序；实现堆的插入、删除堆顶。
4. 判断稳定性：插入、冒泡、归并、基数排序稳定；希尔、快速、简单选择、堆排序不稳定。
5. 比较最好/最坏/平均复杂度和空间；解释“比较排序下界为 $\Omega(n\log n)$”。
6. 根据数据规模、初始有序程度、稳定性、空间限制选择排序算法；外排序为什么常用归并。
