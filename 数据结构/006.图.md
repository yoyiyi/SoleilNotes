## 1 概述

图 $G=(V,E)$ 由非空顶点集 $V$ 和边集 $E$ 组成，用来描述元素之间**多对多**的关系。图是比线性表、树更一般的数据结构。

| 术语 | 含义 |
| --- | --- |
| 有向图 / 无向图 | 边有方向称为弧（`<u,v>`）；边无方向记为 `(u,v)` |
| 完全图 | 无向图任意两个不同顶点间都有边，共 $n(n-1)/2$ 条；有向完全图有 $n(n-1)$ 条弧 |
| 度、入度、出度 | 无向图顶点关联的边数为度；有向图分出度和入度，$\sum out=\sum in=e$ |
| 路径、回路 | 顶点序列；首尾相同的路径为回路，顶点不重复为简单路径 |
| 连通图 | 无向图任意两顶点间有路径；否则分成若干连通分量 |
| 强连通图 | 有向图任意两顶点互相可达；其极大子图为强连通分量 |
| 生成树 | 连通图含全部 $n$ 个顶点、仅 $n-1$ 条边的极小连通子图 |
| 网 | 边或弧带权值的图 |
| 稠密图 / 稀疏图 | 边数接近 $n^2$ 为稠密图；$e$ 远小于 $n^2$ 为稀疏图 |

本章重点：图的存储、遍历、最小生成树、最短路径、拓扑排序和关键路径。

## 2 核心内容

### 2.1 图的存储结构

**邻接矩阵**：用 $n\times n$ 数组 `edge[i][j]` 表示顶点 $i$ 到 $j$ 是否有边或边权。无向图的矩阵对称；有向图第 $i$ 行非零元素个数是出度，第 $j$ 列非零元素个数是入度。优点是判边、增删边 $O(1)$，缺点是空间 $O(n^2)$。

**邻接表**：每个顶点挂一条边链表。有向图通常存出边，求入度需另建逆邻接表；无向图每条边存两次。空间 $O(n+e)$，适合稀疏图，但判断两点是否相邻要遍历链表。

**十字链表**：面向有向图。顶点结点存 `firstin`、`firstout`；弧结点存弧尾 `tailvex`、弧头 `headvex`、同弧头链 `hlink`、同弧尾链 `tlink`。既能快速找入边，也能快速找出边。

**邻接多重表**：面向无向图。每条边只设一个边结点，含 `ivex`、`jvex`、`ilink`、`jlink` 和权值；顶点存一条关联边。删除边和遍历边比邻接表方便，空间 $O(n+e)$。

| 存储结构 | 适用图 | 空间 | 找邻接点 | 特点 |
| --- | --- | --- | --- | --- |
| 邻接矩阵 | 任意图，尤其稠密图 | $O(n^2)$ | $O(n)$ | 判边 $O(1)$，无向图对称 |
| 邻接表 | 任意图，尤其稀疏图 | $O(n+e)$ | $O(outdeg)$ | 出边方便，入边不便 |
| 十字链表 | 有向图 | $O(n+e)$ | $O(outdeg)$ / $O(indeg)$ | 入边、出边都方便 |
| 邻接多重表 | 无向图 | $O(n+e)$ | $O(deg)$ | 一条边只存一个结点，便于删边 |

### 2.2 图的遍历

**深度优先搜索（DFS）**：访问起点后，沿一条未访问的邻边尽量深入；走不通时回溯。递归栈的最大深度为 $O(n)$。对非连通图要对每个未访问顶点重新调用，得到深度优先生成森林。

**广度优先搜索（BFS）**：从起点出发，先访问所有距离为 1 的顶点，再访问距离为 2 的顶点，用队列实现。BFS 得到的是按层扩展的生成树；在**无权图**中，BFS 首次到达某点的层数就是最短路径长度。

邻接矩阵存储时，两种遍历都要检查 $n$ 个邻接位置，时间 $O(n^2)$；邻接表存储时每条边只扫描常数次，时间 $O(n+e)$。空间均为 $O(n)$。

### 2.3 最小生成树

最小生成树（MST）是带权连通无向图中边权之和最小的生成树。依据**切分性质**：把顶点分成两个集合，横跨切分的最小权边一定属于某棵 MST；以及**回路性质**：回路中权值严格大于同回路其他边的边，不在任何 MST 中（若最大权不唯一，则不能直接排除）。

**Prim 算法**：从任意顶点开始，把已选顶点看成集合 $U$，每次选择连接 $U$ 与 $V-U$ 的最小权边，并把新顶点加入 $U$。适合稠密图，邻接矩阵实现 $O(n^2)$，二叉堆优化后 $O(e\log n)$。

**Kruskal 算法**：把所有边按权值从小到大排序，依次尝试加入；若两端点已在同一连通分量中则舍弃，否则合并。用并查集维护连通性，时间 $O(e\log e)$，适合稀疏图。边权各不相同时 MST 唯一。

### 2.4 最短路径

**Dijkstra**：单源最短路，要求边权**非负**。每次从未确定的顶点中选 `dist` 最小者，将其永久确定，再用它松弛邻边。邻接矩阵 $O(n^2)$，堆优化 $O(e\log n)$。负权边会破坏贪心正确性，不能直接使用。

**Floyd**：求任意两点间最短路，本质是动态规划。以 $k$ 为中间点，状态转移为 `d[i][j]=min(d[i][j], d[i][k]+d[k][j])`，$k$ 必须放在最外层。时间 $O(n^3)$，空间 $O(n^2)$，允许负权边，但不能有负权回路。

**Bellman-Ford**：单源最短路，允许负权边。对每条边松弛，最多进行 $n-1$ 轮；若第 $n$ 轮仍能松弛，说明存在从源点可达的负权回路。时间 $O(ne)$，适合含负权边的图。

### 2.5 拓扑排序与关键路径

**AOV 网**：顶点表示活动，有向边表示活动之间的先后约束。拓扑排序反复输出入度为 0 的顶点并删除其出边；若最终输出顶点数小于 $n$，则图中有环。拓扑序列可能不唯一。

**AOE 网**：边表示活动，顶点表示事件，边权表示活动持续时间。一般只有一个源点和一个汇点。计算步骤：

1. 按拓扑序求事件最早发生时间：`ve[v] = max(ve[u] + w(u,v))`，源点 `ve=0`。
2. 按逆拓扑序求事件最迟发生时间：`vl[u] = min(vl[v] - w(u,v))`，汇点 `vl=ve`。
3. 对活动 `<u,v>`：最早开始 `e=ve[u]`，最迟开始 `l=vl[v]-w`，时间余量 `d=l-e`。
4. `d=0` 的活动为关键活动；从源点到汇点由关键活动组成的路径为关键路径，长度等于 `ve[汇点]`。关键路径可能不唯一，缩短关键活动可能改变关键路径。

## 3 算法与代码

以下均以邻接矩阵为例。无权图有边记 1、无边记 0；带权图边权非负、无边记 `INF`。

```c
#include <stdio.h>
#include <string.h>
#include <stdlib.h>
#define MAXV 100
#define INF 0x3f3f3f3f

typedef struct {
    int n, e;
    int edge[MAXV][MAXV];
} MGraph;

void initMatrix(MGraph *g, int n, int weighted) {
    g->n = n; g->e = 0;
    for (int i = 0; i < n; i++)
        for (int j = 0; j < n; j++)
            g->edge[i][j] = (i == j) ? 0 : (weighted ? INF : 0);
}
```

### 3.1 DFS 与 BFS

```c
int visited[MAXV];

void DFS(MGraph *g, int u) {
    visited[u] = 1;
    printf("%d ", u);
    for (int v = 0; v < g->n; v++)
        if (g->edge[u][v] == 1 && !visited[v]) DFS(g, v);
}

void DFSTraverse(MGraph *g) {
    memset(visited, 0, sizeof(visited));
    for (int i = 0; i < g->n; i++)
        if (!visited[i]) DFS(g, i);
}

void BFS(MGraph *g, int s) {
    int q[MAXV], front = 0, rear = 0;
    memset(visited, 0, sizeof(visited));
    visited[s] = 1; q[rear++] = s;
    while (front < rear) {
        int u = q[front++];
        printf("%d ", u);
        for (int v = 0; v < g->n; v++)
            if (g->edge[u][v] == 1 && !visited[v]) {
                visited[v] = 1; q[rear++] = v;
            }
    }
}
```

### 3.2 Prim 算法

```c
void Prim(MGraph *g, int s) {
    int lowcost[MAXV], parent[MAXV], used[MAXV] = {0};
    for (int i = 0; i < g->n; i++) {
        lowcost[i] = g->edge[s][i];
        parent[i] = s;
    }
    used[s] = 1;
    for (int k = 1; k < g->n; k++) {
        int u = -1, min = INF;
        for (int i = 0; i < g->n; i++)
            if (!used[i] && lowcost[i] < min) { min = lowcost[i]; u = i; }
        if (u == -1) return;              // 图不连通
        used[u] = 1;
        printf("(%d,%d) %d\n", parent[u], u, min);
        for (int v = 0; v < g->n; v++)
            if (!used[v] && g->edge[u][v] < lowcost[v]) {
                lowcost[v] = g->edge[u][v];
                parent[v] = u;
            }
    }
}
```

### 3.3 Kruskal 算法

```c
typedef struct { int u, v, w; } Edge;

int cmp(const void *a, const void *b) {
    return ((Edge *)a)->w - ((Edge *)b)->w;
}

int fa[MAXV];
int find(int x) { return fa[x] == x ? x : (fa[x] = find(fa[x])); }

void Kruskal(Edge es[], int n, int m) {
    for (int i = 0; i < n; i++) fa[i] = i;
    qsort(es, m, sizeof(Edge), cmp);
    int cnt = 0;
    for (int i = 0; i < m && cnt < n - 1; i++) {
        int a = find(es[i].u), b = find(es[i].v);
        if (a != b) {
            fa[a] = b;
            printf("(%d,%d) %d\n", es[i].u, es[i].v, es[i].w);
            cnt++;
        }
    }
}
```

### 3.4 Dijkstra 算法

```c
void Dijkstra(MGraph *g, int s) {
    int dist[MAXV], path[MAXV], used[MAXV] = {0};
    for (int i = 0; i < g->n; i++) {
        dist[i] = g->edge[s][i];
        path[i] = (dist[i] < INF) ? s : -1;
    }
    dist[s] = 0; used[s] = 1;
    for (int k = 1; k < g->n; k++) {
        int u = -1, min = INF;
        for (int i = 0; i < g->n; i++)
            if (!used[i] && dist[i] < min) { min = dist[i]; u = i; }
        if (u == -1) break;
        used[u] = 1;
        for (int v = 0; v < g->n; v++)
            if (!used[v] && g->edge[u][v] < INF &&
                dist[u] + g->edge[u][v] < dist[v]) {
                dist[v] = dist[u] + g->edge[u][v];
                path[v] = u;
            }
    }
    for (int i = 0; i < g->n; i++)
        printf("%d: %d\n", i, dist[i] == INF ? -1 : dist[i]);
}
```

### 3.5 Floyd 算法

```c
void Floyd(MGraph *g) {
    int d[MAXV][MAXV];
    for (int i = 0; i < g->n; i++)
        for (int j = 0; j < g->n; j++) d[i][j] = g->edge[i][j];
    for (int k = 0; k < g->n; k++)
        for (int i = 0; i < g->n; i++)
            for (int j = 0; j < g->n; j++)
                if (d[i][k] < INF && d[k][j] < INF &&
                    d[i][k] + d[k][j] < d[i][j])
                    d[i][j] = d[i][k] + d[k][j];
    for (int i = 0; i < g->n; i++)
        if (d[i][i] < 0) printf("存在负权回路\n");
}
```

### 3.6 Bellman-Ford 算法

```c
int BellmanFord(int n, Edge es[], int m, int s, int dist[]) {
    for (int i = 0; i < n; i++) dist[i] = INF;
    dist[s] = 0;
    for (int k = 1; k < n; k++) {
        int changed = 0;
        for (int i = 0; i < m; i++) {
            int u = es[i].u, v = es[i].v, w = es[i].w;
            if (dist[u] < INF && dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w; changed = 1;
            }
        }
        if (!changed) break;
    }
    for (int i = 0; i < m; i++)
        if (dist[es[i].u] < INF && dist[es[i].u] + es[i].w < dist[es[i].v])
            return 0;                     // 存在负权回路
    return 1;
}
```

### 3.7 拓扑排序

```c
int TopoSort(MGraph *g) {
    int indeg[MAXV] = {0}, q[MAXV], front = 0, rear = 0;
    for (int i = 0; i < g->n; i++)
        for (int j = 0; j < g->n; j++)
            if (g->edge[i][j] == 1) indeg[j]++;
    for (int i = 0; i < g->n; i++)
        if (indeg[i] == 0) q[rear++] = i;
    int cnt = 0;
    while (front < rear) {
        int u = q[front++];
        printf("%d ", u); cnt++;
        for (int v = 0; v < g->n; v++)
            if (g->edge[u][v] == 1 && --indeg[v] == 0)
                q[rear++] = v;
    }
    return cnt == g->n;                   // 1 表示是 DAG
}
```

## 4 复杂度/性能对比

| 算法 | 解决的问题 | 时间复杂度 | 空间复杂度 | 适用条件 |
| --- | --- | --- | --- | --- |
| DFS / BFS | 遍历、连通分量、无权最短路 | 矩阵 $O(n^2)$；邻接表 $O(n+e)$ | $O(n)$ | BFS 求无权最短路 |
| Prim | 最小生成树 | $O(n^2)$；堆优化 $O(e\log n)$ | $O(n)$ | 连通无向图，稠密图更优 |
| Kruskal | 最小生成树 | $O(e\log e)$ | $O(n+e)$ | 连通无向图，稀疏图更优 |
| Dijkstra | 单源最短路 | $O(n^2)$；堆优化 $O(e\log n)$ | $O(n)$ | 边权非负 |
| Floyd | 多源最短路 | $O(n^3)$ | $O(n^2)$ | 可有负权，无负权回路 |
| Bellman-Ford | 单源最短路、判负环 | $O(ne)$ | $O(n+e)$ | 可有负权 |
| 拓扑排序 | 判断 DAG、求拓扑序 | $O(n+e)$（邻接表） | $O(n)$ | 有向无环图 |

## 5 典型应用与常考题型

**典型应用**：社交网络和通信网络建模；地图导航中的最短路；网络布线、道路建设中的最小生成树；课程先修关系、编译依赖、任务调度中的拓扑排序；工程工期评估中的关键路径。

**常考题型**：

1. 根据图选择存储结构，或计算邻接矩阵、邻接表的空间和顶点度。
2. 写出给定图的 DFS、BFS 序列，判断生成树/生成森林是否唯一。
3. 用 Prim 或 Kruskal 逐步求 MST，比较两种算法适用场景；边权相同则 MST 可能不唯一。
4. 用 Dijkstra 表格法求单源最短路，注意不能处理负权边；用 Floyd 矩阵推导多源最短路。
5. 判断拓扑序列是否合法、拓扑序列个数或是否存在环；AOE 网求 `ve`、`vl`、`e`、`l` 和关键路径。
6. 复杂度比较：邻接矩阵与邻接表、Prim 与 Kruskal、Dijkstra 与 Bellman-Ford。
