## 1 概述
栈和队列都是**操作受限的线性表**：元素之间仍是“一对一”的逻辑关系，但插入、删除只能在指定端进行。

### 1.1 栈
栈（Stack）是只允许在一端进行插入和删除的线性表，特点是**后进先出**（LIFO，Last In First Out）。

* 栈顶（top）：允许插入、删除的一端。
* 栈底（bottom）：不允许操作的另一端。
* 空栈：不含任何元素的栈。
* 入栈（push）：在栈顶插入元素。
* 出栈（pop）：删除并返回栈顶元素。
### 1.2 队列
队列（Queue）是只允许在一端插入、在另一端删除的线性表，特点是**先进先出**（FIFO，First In First Out）。

* 队头（front）：允许删除的一端。
* 队尾（rear）：允许插入的一端。
* 空队列：不含任何元素的队列。
* 入队（enqueue）：在队尾插入元素。
* 出队（dequeue）：删除并返回队头元素。
### 1.3 基本操作
| 操作 | 栈 | 队列 |
| --- | --- | --- |
| 插入 | push(S, x)，在栈顶插入 | enqueue(Q, x)，在队尾插入 |
| 删除 | pop(S)，删除栈顶 | dequeue(Q)，删除队头 |
| 取顶/取头 | getTop(S) | getFront(Q) |
| 判空 | isEmpty(S) | isEmpty(Q) |
| 清空 | clear(S) | clear(Q) |

栈和队列的插入、删除都只能在端点进行，因此**不能直接访问中间元素**，这是与普通线性表的重要区别。
## 2 存储结构

| 存储方式 | 优点 | 缺点 | 典型场景 |
| --- | --- | --- | --- |
| 顺序栈 | 随机访问、结构简单、无指针开销 | 容量固定，可能溢出 | 表达式求值、递归模拟 |
| 链栈 | 动态扩容，不会栈满 | 有指针开销，不能随机访问 | 元素个数变化大 |
| 顺序队列 | 存储紧凑、实现简单 | 普通顺序队列会“假溢出” | 一般队列 |
| 循环队列 | 复用出队后空出的空间 | 需要区分队空、队满 | 408 最常考的顺序队列 |
| 链队列 | 动态扩容，出队方便 | 有指针开销 | 数据量不确定 |

### 2.1 顺序栈

用一组地址连续的存储单元存放栈元素，另设栈顶指针 `top`。

* `top` 指向栈顶元素时：初始 `top = -1`；栈空条件为 `top == -1`；栈满条件为 `top == MaxSize - 1`。
* `top` 指向栈顶元素的下一个位置时：初始 `top = 0`；栈空条件为 `top == 0`；栈满条件为 `top == MaxSize`。

顺序栈的入栈、出栈、取栈顶都是 $O(1)$，但容量固定，扩容需要重新分配并复制元素。

### 2.2 链栈

链栈通常用单链表实现，**栈顶放在链表头部**，这样入栈、出栈都只需修改头指针，时间复杂度为 $O(1)$。

* 可以带头结点，也可以不带头结点；不带头结点时，空栈条件为 `S == NULL`。
* 链栈一般不会“栈满”，除非内存耗尽。
* 多个链栈共享一段连续空间时，可用“栈顶指针数组 + 可分配空间链”实现，但 408 中较少要求代码。

### 2.3 循环队列

普通顺序队列中，`rear` 一直后移，出队后前面空出的位置无法再利用，可能出现 `rear == MaxSize` 但队列并未真正满的**假溢出**。把数组在逻辑上首尾相接，就得到循环队列：

```text
rear = (rear + 1) % MaxSize
front = (front + 1) % MaxSize
```

设 `front` 指向队头元素，`rear` 指向队尾元素的下一个位置（下一个入队位置），则：

* 入队：`data[rear] = x; rear = (rear + 1) % MaxSize;`
* 出队：`x = data[front]; front = (front + 1) % MaxSize;`
* 队列长度：`(rear - front + MaxSize) % MaxSize`。

此时 `front == rear` 既可能表示队空，也可能表示队满，必须采用额外手段区分。常用的三种处理方式如下。

| 处理方式 | 队空判定 | 队满判定 | 可存元素个数 | 说明 |
| --- | --- | --- | --- | --- |
| 牺牲一个存储单元 | `front == rear` | `(rear + 1) % MaxSize == front` | `MaxSize - 1` | 最常用，实现最简单 |
| 增设 size 计数器 | `size == 0` | `size == MaxSize` | `MaxSize` | 入队 `size++`，出队 `size--` |
| 增设 tag 标志 | `front == rear && tag == 0` | `front == rear && tag == 1` | `MaxSize` | `tag` 记录最后一次操作是入队还是出队 |

采用 `tag` 时，约定 `tag = 1` 表示最后一次是入队，`tag = 0` 表示最后一次是出队。入队后置 `tag = 1`，出队后置 `tag = 0`；只有当 `front == rear` 时才需要看 `tag`。

> 注意：若题目给出的约定是 `front` 指向队头元素的前一个位置，则空、满公式会相应变化。做题时必须先看清 `front`、`rear` 的含义，不能死记公式。

### 2.4 双端队列

双端队列（Deque）允许在**两端**进行插入和删除：

* 输入受限双端队列：只允许在一端插入，两端都可以删除。
* 输出受限双端队列：只允许在一端删除，两端都可以插入。
* 栈可以看作只在一端插入、删除的双端队列；队列可以看作一端只插入、另一端只删除的双端队列。

双端队列常用循环数组实现，需要同时维护 `front` 和 `rear`，并处理两端操作时的下标越界。408 中更多是考查“给定输入序列，判断双端队列能否得到某个输出序列”，通常直接模拟即可。

## 3 基本操作与实现

以下代码均为 C 语言实现，`MaxSize` 为最大容量。

### 3.1 顺序栈

```c
#define MaxSize 50
typedef struct {
    int data[MaxSize];
    int top;              // 指向栈顶元素，初始为 -1
} SqStack;

void InitStack(SqStack *S) { S->top = -1; }

int StackEmpty(SqStack S) { return S.top == -1; }

int Push(SqStack *S, int x) {
    if (S->top == MaxSize - 1) return 0;   // 栈满
    S->data[++S->top] = x;
    return 1;
}

int Pop(SqStack *S, int *x) {
    if (S->top == -1) return 0;            // 栈空
    *x = S->data[S->top--];
    return 1;
}

int GetTop(SqStack S, int *x) {
    if (S.top == -1) return 0;
    *x = S.data[S.top];
    return 1;
}
```

### 3.2 链栈

```c
#include <stdlib.h>
typedef struct LinkNode {
    int data;
    struct LinkNode *next;
} LinkNode, *LiStack;

void InitLiStack(LiStack *S) { *S = NULL; }   // 不带头结点

int LiStackEmpty(LiStack S) { return S == NULL; }

int LiPush(LiStack *S, int x) {
    LinkNode *p = (LinkNode *)malloc(sizeof(LinkNode));
    if (p == NULL) return 0;
    p->data = x;
    p->next = *S;                          // 新结点插在表头
    *S = p;
    return 1;
}

int LiPop(LiStack *S, int *x) {
    if (*S == NULL) return 0;
    LinkNode *p = *S;
    *x = p->data;
    *S = p->next;
    free(p);
    return 1;
}
```

### 3.3 循环队列

下面采用“牺牲一个存储单元”的方式，`front` 指向队头元素，`rear` 指向队尾元素的下一个位置。

```c
#define MaxSize 50
typedef struct {
    int data[MaxSize];
    int front, rear;
} SqQueue;

void InitQueue(SqQueue *Q) { Q->front = Q->rear = 0; }

int QueueEmpty(SqQueue Q) { return Q.front == Q.rear; }

int QueueFull(SqQueue Q) { return (Q.rear + 1) % MaxSize == Q.front; }

int EnQueue(SqQueue *Q, int x) {
    if (QueueFull(*Q)) return 0;
    Q->data[Q->rear] = x;
    Q->rear = (Q->rear + 1) % MaxSize;
    return 1;
}

int DeQueue(SqQueue *Q, int *x) {
    if (QueueEmpty(*Q)) return 0;
    *x = Q->data[Q->front];
    Q->front = (Q->front + 1) % MaxSize;
    return 1;
}

int QueueLength(SqQueue Q) {
    return (Q.rear - Q.front + MaxSize) % MaxSize;
}
```

若改用 `size` 计数，只需在结构中增加 `int size;`：入队成功后 `size++`，出队成功后 `size--`；队空为 `size == 0`，队满为 `size == MaxSize`，此时数组的 `MaxSize` 个单元都能使用。

### 3.4 括号匹配

扫描表达式，遇到左括号就入栈；遇到右括号时，若栈空或栈顶不是对应的左括号，则匹配失败；扫描结束后栈必须为空。

```c
int BracketMatch(const char *s) {
    char st[MaxSize];
    int top = -1;
    for (int i = 0; s[i] != '\0'; i++) {
        char c = s[i];
        if (c == '(' || c == '[' || c == '{') {
            if (top == MaxSize - 1) return 0; st[++top] = c;
        } else if (c == ')' || c == ']' || c == '}') {
            if (top == -1) return 0;
            char t = st[top--];
            if ((c == ')' && t != '(') ||
                (c == ']' && t != '[') ||
                (c == '}' && t != '{')) return 0;
        }
    }
    return top == -1;
}
```

### 3.5 队列实现 BFS

广度优先搜索按“先发现的顶点先访问”的顺序扩展，因此用队列保存待访问顶点。下面以邻接矩阵为例：

```c
#define MAXV 100
void BFS(int G[][MAXV], int n, int v) {
    int visited[MAXV] = {0};
    int q[MAXV], front = 0, rear = 0;
    visited[v] = 1;
    q[rear++] = v;
    while (front != rear) {
        int u = q[front++];
        printf("%d ", u);
        for (int w = 0; w < n; w++) {
            if (G[u][w] && !visited[w]) {
                visited[w] = 1;
                q[rear++] = w;             // 每个顶点最多入队一次
            }
        }
    }
}
```

## 4 复杂度与特性对比

| 操作/结构 | 顺序栈 | 链栈 | 循环队列 | 链队列 |
| --- | --- | --- | --- | --- |
| 入栈/入队 | $O(1)$ | $O(1)$ | $O(1)$ | $O(1)$ |
| 出栈/出队 | $O(1)$ | $O(1)$ | $O(1)$ | $O(1)$ |
| 取栈顶/队头 | $O(1)$ | $O(1)$ | $O(1)$ | $O(1)$ |
| 查找中间元素 | $O(n)$ | $O(n)$ | $O(n)$ | $O(n)$ |
| 空间 | 固定，可能溢出 | 动态，有指针开销 | 固定，浪费一个单元 | 动态，有指针开销 |

| 算法 | 时间复杂度 | 空间复杂度 |
| --- | --- | --- |
| 括号匹配 | $O(n)$ | $O(n)$ |
| 中缀转后缀 | $O(n)$ | $O(n)$ |
| 后缀表达式求值 | $O(n)$ | $O(n)$ |
| BFS（邻接表） | $O(V+E)$ | $O(V)$ |
| BFS（邻接矩阵） | $O(V^2)$ | $O(V)$ |

## 5 典型应用

### 5.1 表达式求值

中缀表达式受运算符优先级和括号影响，计算机通常先转成后缀表达式再求值：

1. 从左到右扫描中缀表达式，操作数直接输出。
2. 遇到左括号入栈；遇到右括号，弹出并输出栈顶运算符，直到弹出左括号（左括号不输出）。
3. 遇到运算符时，若栈顶不是左括号且栈顶运算符优先级不低于当前运算符，则先弹出并输出栈顶，再让当前运算符入栈。
4. 扫描结束后，依次弹出栈中剩余运算符。

后缀表达式求值时，操作数入栈；遇到运算符则弹出两个操作数，先弹出的是右操作数，后弹出的是左操作数，运算结果再入栈。例如 `3+4*2-(1+1)` 的后缀形式为 `3 4 2 * + 1 1 + -`，结果为 `9`。

### 5.2 递归

递归调用本质上是借助**系统调用栈**保存返回地址、参数和局部变量。函数返回时从栈顶恢复现场，因此递归的执行顺序符合后进先出。递归深度过大可能导致栈溢出；尾递归可以改写为循环，从而把空间复杂度降为 $O(1)$。

### 5.3 其他应用

* 括号匹配、HTML/XML 标签匹配。
* 函数调用、递归、深度优先搜索（DFS）的非递归实现。
* 浏览器前进/后退、编辑器撤销/重做（用两个栈）。
* 队列用于 BFS、操作系统进程调度、打印缓冲区、消息队列。
* 用两个栈可以模拟队列；用两个队列可以模拟栈。

## 6 常考题型与小结

* 判断合法出栈序列：模拟入栈、出栈过程；$n$ 个元素的不同出栈序列个数为卡特兰数 $\frac{1}{n+1}\binom{2n}{n}$。
* 循环队列：给定 `front`、`rear` 和 `MaxSize`，求队长、判空、判满；注意题目采用“牺牲单元”“size”“tag”中的哪一种。
* 双端队列：给定输入序列和双端队列的限制，判断输出序列是否可能。
* 表达式：中缀转后缀、后缀求值、前缀/中缀/后缀之间的转换。
* 栈与队列的互相模拟：两个栈模拟队列时，一个负责入队，一个负责出队；两个队列模拟栈时，每次把前 $n-1$ 个元素移到另一个队列。
* 算法设计：用栈实现进制转换、判断回文、求表达式值；用队列实现 BFS、层次遍历。

小结：栈和队列的差别只在“操作端”，但由此带来了 LIFO 与 FIFO 两种完全不同的访问次序。顺序存储要重点掌握循环队列的空满判定，链式存储要重点掌握头插/头删的指针操作。
