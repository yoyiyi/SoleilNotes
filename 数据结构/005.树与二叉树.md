## 1 概述
### 1.1 树的定义
树（Tree）是 $n$（$n \ge 0$）个结点的有限集合。$n=0$ 时为空树；$n>0$ 时有且仅有一个根结点，其余结点可分为若干互不相交的有限集合，每个集合又是一棵树，称为根的子树。树是**一对多**的非线性结构，除根外每个结点有且仅有一个双亲。

### 1.2 基本术语
| 术语 | 含义 |
| --- | --- |
| 结点的度 | 结点拥有的子树（孩子）个数 |
| 树的度 | 所有结点度的最大值 |
| 叶子结点 | 度为 0 的结点，也称终端结点 |
| 分支结点 | 度大于 0 的结点 |
| 内部结点 | 除根以外的分支结点 |
| 层次、深度 | 根为第 1 层；深度常指从根到结点的层数，按题目约定 |
| 高度 | 从结点到最远叶子的最长路径上的结点数；树的高度为最大层数 |
| 森林 | $m$ 棵互不相交的树的集合 |

有序树的孩子次序不能交换，无序树不区分次序；408 中一般默认讨论有序树。

### 1.3 二叉树及其性质
二叉树是 $n$ 个结点的有限集合，或为空，或由一个根结点及两棵互不相交的左、右子树组成。每个结点**至多两个孩子**，左右子树有严格次序。以下性质中的高度按结点层数计。

* 满二叉树：高度为 $h$ 且含 $2^h-1$ 个结点，每层都达到最大结点数。
* 完全二叉树：除最后一层外各层都满，最后一层结点从左到右连续排列。
* 斜树：所有结点只有左孩子或只有右孩子。

| 性质 | 结论 |
| --- | --- |
| 第 $i$ 层结点数 | 至多 $2^{i-1}$ 个（$i \ge 1$） |
| 高度为 $h$ 的结点数 | 至多 $2^h-1$ 个 |
| 结点数与高度 | $n$ 个结点的二叉树高度至少为 $\lceil \log_2(n+1) \rceil$ |
| 叶子与度为 2 的结点 | $n_0=n_2+1$ |
| 完全二叉树高度 | $h=\lfloor \log_2 n \rfloor+1$ |

**$n_0=n_2+1$ 的推导**：设度为 0、1、2 的结点数为 $n_0,n_1,n_2$，则 $n=n_0+n_1+n_2$。除根外每个结点有一条来自双亲的边，故边数为 $n-1$；边数又等于度之和 $n_1+2n_2$。所以

```text
n0 + n1 + n2 - 1 = n1 + 2n2  =>  n0 = n2 + 1
```

**完全二叉树编号关系**：含 $n$ 个结点的完全二叉树从根开始按层、从左到右从 1 编号，对结点 $i$：

* 双亲为 $\lfloor i/2 \rfloor$（$i>1$）。
* 左孩子为 $2i$，存在当且仅当 $2i \le n$。
* 右孩子为 $2i+1$，存在当且仅当 $2i+1 \le n$。
* 结点 $i$ 的层次为 $\lfloor \log_2 i \rfloor+1$。
* 叶子满足 $i > \lfloor n/2 \rfloor$。

推导：第 $k$ 层第一个结点编号为 $2^{k-1}$。设结点 $i$ 是该层第 $r$ 个结点（$r$ 从 0 开始），则 $i=2^{k-1}+r$；其左孩子是下一层第 $2r+1$ 个结点，编号为 $2^k+2r=2i$，右孩子为 $2i+1$。

完全二叉树中，$n$ 为偶数时 $n_1=1$、$n_0=n/2$；$n$ 为奇数时 $n_1=0$、$n_0=(n+1)/2=\lceil n/2 \rceil$。

## 2 存储结构
### 2.1 二叉树的存储
| 存储方式 | 结构 | 特点 |
| --- | --- | --- |
| 顺序存储 | 数组按下标存放，根在下标 1 | 适合完全二叉树，父子下标可直接计算；一般二叉树浪费空间 |
| 二叉链表 | 结点含 `lchild`、`data`、`rchild` | 最常用，找孩子方便，找双亲不便 |
| 三叉链表 | 二叉链表增加 `parent` 指针 | 找双亲方便，指针开销更大 |

含 $n$ 个结点的二叉链表有 $2n$ 个指针域，其中 $n-1$ 个指向孩子，故有 $n+1$ 个空指针域，可用于线索化。

### 2.2 树和森林的存储
| 表示法 | 做法 | 优点 | 缺点 |
| --- | --- | --- | --- |
| 双亲表示法 | 数组存放结点及双亲下标 | 找双亲 $O(1)$ | 找孩子需扫描 |
| 孩子表示法 | 每个结点挂一个孩子链表 | 找孩子方便 | 找双亲不便 |
| 孩子兄弟表示法 | 左指针指第一个孩子，右指针指下一个兄弟 | 可与二叉树相互转换 | 找双亲需额外信息 |

孩子兄弟表示法又称二叉链表表示法，是树、森林与二叉树转换的基础。

## 3 基本操作与实现
### 3.1 二叉树的遍历
```c
typedef char ElemType;
typedef struct BiTNode {
    ElemType data;
    struct BiTNode *lchild, *rchild;
} BiTNode, *BiTree;
```

先序为“根、左、右”，中序为“左、根、右”，后序为“左、右、根”。递归实现：

```c
void PreOrder(BiTree T) {
    if (T) { printf("%c ", T->data); PreOrder(T->lchild); PreOrder(T->rchild); }
}
void InOrder(BiTree T) {
    if (T) { InOrder(T->lchild); printf("%c ", T->data); InOrder(T->rchild); }
}
void PostOrder(BiTree T) {
    if (T) { PostOrder(T->lchild); PostOrder(T->rchild); printf("%c ", T->data); }
}
```

非递归遍历用显式栈。设栈元素类型为 `BiTree`，已实现 `InitStack`、`StackEmpty`、`Push`、`Pop`、`GetTop`：

```c
void PreOrderNR(BiTree T) {
    Stack S; InitStack(&S); BiTree p = T;
    while (p || !StackEmpty(&S)) {
        if (p) { printf("%c ", p->data); Push(&S, p); p = p->lchild; }
        else { p = Pop(&S); p = p->rchild; }
    }
}
void InOrderNR(BiTree T) {
    Stack S; InitStack(&S); BiTree p = T;
    while (p || !StackEmpty(&S)) {
        if (p) { Push(&S, p); p = p->lchild; }
        else { p = Pop(&S); printf("%c ", p->data); p = p->rchild; }
    }
}
void PostOrderNR(BiTree T) {
    Stack S; InitStack(&S); BiTree p = T, last = NULL;
    while (p || !StackEmpty(&S)) {
        if (p) { Push(&S, p); p = p->lchild; }
        else {
            p = GetTop(&S);
            if (p->rchild && p->rchild != last) p = p->rchild;
            else { p = Pop(&S); printf("%c ", p->data); last = p; p = NULL; }
        }
    }
}
```

后序遍历中，`last` 记录上一个访问的结点；只有右子树为空或已访问过，才能访问根。

层次遍历按层从上到下、每层从左到右访问，借助队列（设 `MAXN` 为结点数上限）：

```c
void LevelOrder(BiTree T) {
    if (!T) return;
    BiTree q[MAXN]; int front = 0, rear = 0;
    q[rear++] = T;
    while (front < rear) {
        BiTree p = q[front++];
        printf("%c ", p->data);
        if (p->lchild) q[rear++] = p->lchild;
        if (p->rchild) q[rear++] = p->rchild;
    }
}
```

### 3.2 由遍历序列构造二叉树
* 先序 + 中序：先序首元素是根，在中序中定位根即可划分左右子树，递归构造。
* 后序 + 中序：后序末元素是根，同样用中序划分。
* 层次 + 中序：层次首元素是根，按中序划分后，再按层次顺序分配结点。
* 先序 + 后序：一般不能唯一确定二叉树，无法区分只有一个孩子时是左还是右。

### 3.3 线索二叉树
二叉链表有 $n+1$ 个空指针，可存放某种遍历次序下的前驱、后继，得到线索二叉树。建树时先把所有结点的 `ltag`、`rtag` 置 0；`ltag=1` 表示 `lchild` 指向前驱，`rtag=1` 表示 `rchild` 指向后继；为 0 时仍指向孩子。

```c
typedef struct ThreadNode {
    char data;
    struct ThreadNode *lchild, *rchild;
    int ltag, rtag;
} ThreadNode, *ThreadTree;

ThreadTree pre = NULL;
void InThread(ThreadTree p) {
    if (!p) return;
    InThread(p->lchild);
    if (!p->lchild) { p->lchild = pre; p->ltag = 1; }
    if (pre && !pre->rchild) { pre->rchild = p; pre->rtag = 1; }
    pre = p;
    InThread(p->rchild);
}
void CreateInThread(ThreadTree T) {
    pre = NULL;
    if (T) { InThread(T); if (!pre->rchild) pre->rtag = 1; }
}
```

中序线索树中，`rtag=1` 时 `rchild` 即后继；否则后继是右子树最左下的结点，因此遍历不需要栈：

```c
ThreadTree FirstNode(ThreadTree p) { while (p && p->ltag == 0) p = p->lchild; return p; }
ThreadTree NextNode(ThreadTree p) {
    if (p->rtag == 0) return FirstNode(p->rchild);
    return p->rchild;
}
void InOrderThread(ThreadTree T) {
    for (ThreadTree p = FirstNode(T); p; p = NextNode(p)) printf("%c ", p->data);
}
```

线索化后遍历时间 $O(n)$、额外空间 $O(1)$，但插入、删除时维护线索较复杂。

### 3.4 树、森林与二叉树的转换
采用“**左孩子右兄弟**”规则：

1. 每个结点的第一个孩子，作为转换后该结点的左孩子。
2. 每个结点的下一个兄弟，作为转换后该结点的右孩子。
3. 森林中每棵树的根互为兄弟，依次用右指针连接。

转换后二叉树的先序对应原树的先序，中序对应原树的后序；森林的先序、后序分别对应所生成二叉树的先序、中序。反过来，沿左指针找到第一个孩子，沿右指针找到所有兄弟，即可还原树或森林。

### 3.5 哈夫曼树与哈夫曼编码
哈夫曼树是带权路径长度 WPL 最小的二叉树。叶子的带权路径长度为 $w_i \times l_i$，$l_i$ 为根到叶子的边数；整棵树的 WPL 为所有叶子带权路径长度之和。

构造：把 $n$ 个权值看成 $n$ 棵单结点树；每次选两棵根权值最小的树合并，新根权值为两者之和；重复直到只剩一棵树。

以 $\{1,2,3,4,5\}$ 为例：合并 $1+2=3$，再合并 $3+3=6$，再合并 $4+5=9$，最后合并 $6+9=15$。WPL 等于所有合并产生的新结点权值之和：

```text
WPL = 3 + 6 + 9 + 15 = 33
```

规定左分支为 0、右分支为 1，可得编码：1→000，2→001，3→01，4→10，5→11。编码不唯一，但 WPL 相同；它是**前缀编码**，任一编码都不是另一编码的前缀。哈夫曼树没有度为 1 的结点，$n$ 个叶子对应 $2n-1$ 个结点，平均码长为 $\text{WPL}/\sum w_i$。

### 3.6 二叉排序树
二叉排序树（BST）满足：左子树所有关键字小于根，右子树所有关键字大于根，左右子树也为 BST。中序遍历 BST 得到递增序列。

```c
typedef struct BSTNode {
    int key;
    struct BSTNode *lchild, *rchild;
} BSTNode, *BSTree;

BSTree BSTSearch(BSTree T, int key) {
    while (T && key != T->key)
        T = (key < T->key) ? T->lchild : T->rchild;
    return T;
}
int BSTInsert(BSTree *T, int key) {
    if (*T == NULL) {
        *T = (BSTNode *)malloc(sizeof(BSTNode));
        if (*T == NULL) return 0;
        (*T)->key = key; (*T)->lchild = (*T)->rchild = NULL;
        return 1;
    }
    if (key == (*T)->key) return 0;
    if (key < (*T)->key) return BSTInsert(&(*T)->lchild, key);
    return BSTInsert(&(*T)->rchild, key);
}
```

删除分三种情况：叶子直接删；只有一个孩子时用孩子替代；有两个孩子时，用中序前驱或后继的值替代，再删除那个前驱/后继结点。BST 查找、插入、删除平均 $O(\log n)$，按有序序列插入会退化成单支树，最坏 $O(n)$。

### 3.7 平衡二叉树（AVL）
AVL 树是任意结点左右子树高度差绝对值不超过 1 的二叉排序树。平衡因子 $\text{BF}=\text{左高}-\text{右高}$，只能为 $-1,0,1$。插入失衡时，对**最小不平衡子树**按插入位置旋转：

| 类型 | 插入位置 | 旋转 |
| --- | --- | --- |
| LL | 左孩子的左子树 | 对根右旋一次 |
| RR | 右孩子的右子树 | 对根左旋一次 |
| LR | 左孩子的右子树 | 先对左孩子左旋，再对根右旋 |
| RL | 右孩子的左子树 | 先对右孩子右旋，再对根左旋 |

```c
typedef struct AVLNode {
    int key, height; struct AVLNode *lchild, *rchild;
} AVLNode, *AVLTree;
int Height(AVLTree T) { return T ? T->height : 0; }
int Max(int a, int b) { return a > b ? a : b; }
void UpdateHeight(AVLTree T) { T->height = Max(Height(T->lchild), Height(T->rchild)) + 1; }
AVLTree RightRotate(AVLTree y) {
    AVLTree x = y->lchild, t2 = x->rchild;
    x->rchild = y; y->lchild = t2;
    UpdateHeight(y); UpdateHeight(x);
    return x;
}
AVLTree LeftRotate(AVLTree x) {
    AVLTree y = x->rchild, t2 = y->lchild;
    y->lchild = x; x->rchild = t2;
    UpdateHeight(x); UpdateHeight(y);
    return y;
}
```

插入后沿递归返回路径更新高度：LL 直接右旋，RR 直接左旋，LR 先左旋左孩子再右旋根，RL 先右旋右孩子再左旋根。旋转不改变中序序列；AVL 查找、插入、删除均为 $O(\log n)$。

## 4 复杂度与特性对比
| 结构/算法 | 时间复杂度 | 空间复杂度 | 说明 |
| --- | --- | --- | --- |
| 二叉树遍历 | $O(n)$ | $O(h)$ | 递归栈或显式栈深为树高 |
| 层次遍历 | $O(n)$ | $O(w)$ | $w$ 为最大层结点数 |
| 中序线索遍历 | $O(n)$ | $O(1)$ | 不需栈 |
| BST 查找/插入/删除 | 平均 $O(\log n)$，最坏 $O(n)$ | $O(h)$ | 递归栈；迭代查找为 $O(1)$ |
| AVL 查找/插入/删除 | $O(\log n)$ | $O(\log n)$ | 递归栈 |
| 哈夫曼树构造 | $O(n \log n)$ | $O(n)$ | 用优先队列选最小权值 |

## 5 典型应用
* 表达式树：叶子为操作数，内部结点为运算符；先序、中序、后序分别对应前缀、中缀、后缀表达式。
* 哈夫曼编码：按频率构造最优前缀码，用于 ZIP、图像压缩等。
* 二叉排序树与 AVL：动态集合的查找、插入、删除；AVL 用于需要稳定 $O(\log n)$ 的索引场景。
* 堆：完全二叉树的顺序存储，实现优先队列、调度和 Top-K。
* 文件系统、语法树、决策树等都具有树形层次结构。

## 6 常考题型与小结
* 用 $n_0=n_2+1$、完全二叉树编号关系求结点数、叶子数和高度。
* 写先序/中序/后序/层次序列；由两种序列还原二叉树；判断序列是否合法。
* 写非递归遍历的栈变化，或求某结点在后序中的前驱/后继。
* 画中序线索二叉树并填写空指针线索。
* 树、森林与二叉树互转，判断转换前后的遍历序列对应关系。
* 构造哈夫曼树，计算 WPL、平均码长，判断编码是否合法。
* BST 插入、删除；AVL 插入后判断旋转类型并画结果。

小结：性质、遍历和存储是树这一章的基础；遍历要能从递归写到非递归；树/森林转换牢记“左孩子右兄弟”；哈夫曼树抓住 WPL 最小和前缀编码；BST 与 AVL 则分别解决有序性和平衡性问题。
