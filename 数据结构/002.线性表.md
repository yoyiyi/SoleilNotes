## 1 定义

线性表是具有**相同数据类型**的 n 个数据元素的有限序列，n 为表长，n = 0 为空表。

* 除第一个元素外，每个元素有且仅有一个直接前驱。
* 除最后一个元素外，每个元素有且仅有一个直接后继。
* 元素之间是**一对一**的逻辑关系，属于线性结构。

## 2 顺序表

一组地址连续的存储单元依次存储线性表中的数据元素，逻辑上相邻的元素在物理位置上也相邻。

### 2.1 静态分配

```c
#define MaxSize 10
typedef struct {
    ElemType data[MaxSize];   // 静态数组存放数据元素
    int length;               // 当前长度
} SqList;
```

静态分配的容量在编译期确定，表满后无法扩容。

### 2.2 动态分配

```c
#define InitSize 10
typedef struct {
    ElemType *data;   // 动态分配数组的指针
    int MaxSize;      // 最大容量
    int length;       // 当前长度
} SeqList;

void InitList(SeqList *L) {
    L->data = (ElemType *)malloc(sizeof(ElemType) * InitSize);
    L->MaxSize = InitSize;
    L->length = 0;
}
```

扩容时需要申请一块更大的连续空间并整体搬迁，这就是顺序表「插入删除慢」的根源。

### 2.3 基本操作与复杂度

| 操作 | 做法 | 时间复杂度 |
| --- | --- | --- |
| 按位查找 | `data[i-1]` 直接访问 | O(1) |
| 按值查找 | 从前往后比较 | O(n) |
| 插入 | 第 i 个位置及其后元素后移一位 | O(n)，平均移动 n/2 个元素 |
| 删除 | 第 i 个位置之后的元素前移一位 | O(n)，平均移动 (n-1)/2 个元素 |

插入的代码（注意从后往前移动，避免覆盖）：

```c
bool ListInsert(SqList *L, int i, ElemType e) {
    if (i < 1 || i > L->length + 1) return false;  // 位序非法
    if (L->length >= MaxSize) return false;        // 存储空间已满
    for (int j = L->length; j >= i; j--) {
        L->data[j] = L->data[j - 1];               // 后移
    }
    L->data[i - 1] = e;
    L->length++;
    return true;
}
```

删除的代码：

```c
bool ListDelete(SqList *L, int i, ElemType *e) {
    if (i < 1 || i > L->length) return false;
    *e = L->data[i - 1];
    for (int j = i; j < L->length; j++) {
        L->data[j - 1] = L->data[j];               // 前移
    }
    L->length--;
    return true;
}
```

顺序表的特点是：**随机访问 O(1)，插入删除 O(n)，存储密度高，但需要连续空间且扩容代价大**。

## 3 链表

用一组任意的存储单元存储线性表的数据元素，逻辑相邻的元素物理上不必相邻，靠指针维系逻辑关系。

### 3.1 单链表

每个结点包含数据域和指针域，指针指向下一个结点。通常设置**头结点**，可以让空表与非空表、首元结点与其他结点的操作统一起来。

```c
typedef struct LNode {
    ElemType data;
    struct LNode *next;
} LNode, *LinkList;
```

按位查找与插入：

```c
LNode *GetElem(LinkList L, int i) {
    if (i < 0) return NULL;
    LNode *p = L;                 // L 为头结点，i = 0 时返回头结点
    int j = 0;
    while (p != NULL && j < i) {
        p = p->next;
        j++;
    }
    return p;
}

bool InsertNextNode(LNode *p, ElemType e) {   // 在 p 之后插入
    if (p == NULL) return false;
    LNode *s = (LNode *)malloc(sizeof(LNode));
    if (s == NULL) return false;
    s->data = e;
    s->next = p->next;
    p->next = s;
    return true;
}
```

删除 p 的后继结点：

```c
bool DeleteNextNode(LNode *p) {
    if (p == NULL || p->next == NULL) return false;
    LNode *q = p->next;
    p->next = q->next;
    free(q);
    return true;
}
```

**尾插法建表**需要始终维护尾指针；**头插法建表**会把输入顺序逆转，常用来做链表逆置。删除结点 p 本身时，如果只知道 p，可以「复制后继的数据到 p，再删后继」，这也是单链表题的常用技巧。

### 3.2 双链表

结点中增加一个指向前驱的指针，可以 O(1) 找到前驱，插入删除不必再从头遍历。

```c
typedef struct DNode {
    ElemType data;
    struct DNode *prior, *next;
} DNode, *DLinkList;
```

在 p 之后插入 s，四步顺序不能乱：

```c
s->next = p->next;
if (p->next != NULL) p->next->prior = s;
s->prior = p;
p->next = s;
```

### 3.3 循环链表

* **循环单链表**：尾结点的 next 指向头结点，判空条件是 `L->next == L`。从任意结点出发都能遍历全表，且可以在 O(1) 时间内找到表尾（保存尾指针时）。
* **循环双链表**：头结点的 prior 指向尾结点，`L->next == L && L->prior == L` 表示空表。

### 3.4 静态链表

用数组模拟链表，每个结点存数据和一个「下一个结点的数组下标」（游标），适合不支持指针的语言。`next == -1` 表示表尾。

## 4 顺序表与链表的对比

| 维度 | 顺序表 | 链表 |
| --- | --- | --- |
| 存储方式 | 连续空间，随机访问 | 离散空间，顺序访问 |
| 查找 | 按位 O(1)，按值 O(n) | 按位 O(n)，按值 O(n) |
| 插入删除 | O(n)，需移动元素 | O(1)（已知前驱时） |
| 空间 | 需要预分配，可能浪费 | 按需分配，但每结点多一个指针域 |
| 适用场景 | 表长稳定、频繁查询 | 表长变化大、频繁插入删除 |

## 5 常考题型

* 用 O(1) 空间把单链表逆置（头插法）。
* 找链表的中间结点（快慢指针）。
* 判断链表是否有环，并求环的入口（快慢指针相遇后重新从头出发）。
* 合并两个有序链表、删除倒数第 k 个结点（双指针间隔 k）。
* 判断回文链表（找中点 + 逆置后半段 + 比较）。
* 两个链表求第一个公共结点（长度差对齐后同步走）。
