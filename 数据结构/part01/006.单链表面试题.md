本文件汇总 8 道单链表高频题，代码为简洁版，默认 `ListNode` 含 `val` 与 `next` 字段。
## 1 反转链表

迭代 `pre/cur` 逐个改向；递归先反转 `head.next` 再回接。时间 O(n)，迭代空间 O(1)、递归 O(n)。

```c
struct ListNode *pre = NULL, *n;
for (; h; h = n) { n = h->next; h->next = pre; pre = h; }
// 返回 pre
```
## 2 求中间结点

快慢指针，`fast` 两步、`slow` 一步；偶数个结点返回下中点。时间 O(n)，空间 O(1)。

```java
ListNode s = h, f = h;
while (f != null && f.next != null) { s = s.next; f = f.next.next; }
// 返回 s（偶数个时为下中点）
```

## 3 判断环与环入口

相遇则有环；相遇后一指针回头，同速再遇即入口（`a = c + (n-1)(b+c)`）。时间 O(n)，空间 O(1)。

```java
ListNode s = h, f = h;
while (f != null && f.next != null) {
    s = s.next; f = f.next.next;
    if (s == f) { while (s != h) { s = s.next; h = h.next; } return h; }
}
return null;
```

## 4 合并两个有序链表

哑结点 + 尾指针，每次接较小结点，剩余部分直接接上。时间 O(m+n)，空间 O(1)。

```java
ListNode d = new ListNode(0), t = d;
while (a != null && b != null) {
    if (a.val <= b.val) { t.next = a; a = a.next; } else { t.next = b; b = b.next; }
    t = t.next;
}
t.next = a != null ? a : b; // 返回 d.next
```

## 5 删除倒数第 k 个结点

`fast` 先走 k 步，再同步走；`slow` 停在待删前驱，哑结点统一删头。时间 O(n)，空间 O(1)。

```java
ListNode d = new ListNode(0), s = d, f = d; d.next = h;
while (k-- > 0) f = f.next;
while (f.next != null) { s = s.next; f = f.next; }
s.next = s.next.next; // 返回 d.next
```

## 6 两个链表相交

两指针走完自己换到另一条链，总路程相同，相遇即交点。时间 O(m+n)，空间 O(1)。

```java
ListNode ha = a, hb = b;
while (a != b) { a = a == null ? hb : a.next; b = b == null ? ha : b.next; }
// 返回 a（无交点时为 null）
```

## 7 每 k 个一组翻转

先数长度，够 k 才翻；组内头插反转，接好前驱与后继。时间 O(n)，空间 O(1)。

```java
ListNode d = new ListNode(0); d.next = h;
for (ListNode pre = d; ; ) {
    ListNode tail = pre;
    for (int i = 0; i < k && tail != null; i++) tail = tail.next;
    if (tail == null) return d.next;
    ListNode cur = pre.next, nx = tail.next;
    for (int i = 0; i < k; i++) { ListNode t = cur.next; cur.next = nx; nx = cur; cur = t; }
    ListNode old = pre.next; pre.next = nx; pre = old;
}
```

## 8 回文链表

快慢找中点，反转后半，逐个比较；需要恢复可再反转一次。时间 O(n)，空间 O(1)。

```java
ListNode s = h, f = h, pre = null;
while (f != null && f.next != null) { s = s.next; f = f.next.next; }
while (s != null) { ListNode n = s.next; s.next = pre; pre = s; s = n; }
while (pre != null) { if (pre.val != h.val) return false; pre = pre.next; h = h.next; }
return true;
```

## 9 面试问答
* **反转链表的递归为什么是 O(n) 空间？** 递归深度等于链表长度，每层保存返回地址与局部变量；链表过长会栈溢出，工程上优先迭代。
* **环入口的数学依据？** 设头到入口为 a、入口到相遇点为 b、环长为 b+c，由 2(a+b)=a+b+n(b+c) 得 a=c+(n-1)(b+c)，故同速必在入口相遇。
* **删除倒数第 k 个为什么要哑结点？** k 等于链表长度时删的是头结点，哑结点让「前驱」始终存在，代码统一。
* **链表题常见坑？** 先保存 next 再改指针；注意空表、单结点、k 越界；比较相交/回文时分清引用与值。
