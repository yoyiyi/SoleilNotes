## 1 什么是滑动窗口

滑动窗口用两个指针 `left`、`right` 维护原序列上的一个连续区间（窗口），右指针负责扩张、左指针负责收缩，在窗口滑动的过程中增量维护统计量并更新答案。

* 本质是「双指针 + 区间信息维护」，把枚举所有区间的 O(n^2) 优化到 O(n)。
* 每个元素最多被 `right` 加入一次、被 `left` 移出一次，所以指针移动的总次数是 2n。
* 与暴力法的区别：暴力法每个区间都重新算一遍，滑动窗口只做「加入一个元素」和「移出一个元素」的增量更新。

## 2 适用条件

* 答案是原序列的一个**连续**区间（连续子数组/子串），而不是子序列或任意集合。
* 窗口的统计量具有**单调性**：窗口扩张时统计量单调变化（和变大、不同字符数变多），收缩时反向变化，这样才能用「不满足就收缩」逐步逼近最优。
* 统计量可以增量维护：区间和、字符计数、窗口内最值等。
* 反例：子序列问题（不连续）、需要频繁查询区间第 k 大的问题，一般不适合滑动窗口。

## 3 通用模板

右扩左缩：`right` 一直向右移动，每加入一个元素后，如果窗口不满足条件就移动 `left` 直到重新满足；此时窗口就是以 `right` 结尾的「最优窗口」之一。

```java
class Solution {
    public int slidingWindow(int[] nums, int target) {
        int left = 0, right = 0;
        int windowSum = 0; // 窗口内的统计量
        int res = 0;       // 答案
        while (right < nums.length) {
            int c = nums[right];
            right++;
            windowSum += c;              // 右扩：把 c 加入窗口
            while (windowSum > target) { // 左缩：窗口不满足条件时
                int d = nums[left];
                left++;
                windowSum -= d;          // 把 d 移出窗口
            }
            res = Math.max(res, right - left); // 收缩完成后窗口合法
        }
        return res;
    }
}
```

* 四个要素：统计量（sum/count）、扩张操作、收缩条件、答案更新时机。
* 求最长/最大窗口时在**收缩之后**更新答案；求最短/最小窗口时在**收缩之前**更新答案。

## 4 固定窗口与可变窗口

| 类型 | 特征 | 收缩方式 | 代表题 |
| --- | --- | --- | --- |
| 可变窗口 | 窗口大小不固定，由条件决定 | `while (不满足条件)` 收缩 | 3、209、76 |
| 固定窗口 | 窗口大小恒为 k | `if (right - left > k)` 或 `while (right - left > k)` | 567、643、239 |

* 固定窗口：先让 `right` 走到 k，之后每加入一个元素就移出一个，窗口长度始终为 k，可以少写一层内层循环。
* 可变窗口：内层必须用 `while`，因为一次扩张可能触发多次收缩。
* 固定窗口的「收缩」用 `if` 就够了，因为每次只会超出 1 个元素。

## 5 最大窗口与最小窗口

* 最大窗口（求最长）：目标是窗口尽量长，所以只在「不合法」时收缩，收缩完成后用 `[left, right)` 长度更新答案。
* 最小窗口（求最短）：目标是窗口尽量短，所以一旦「合法」就先更新答案，再继续收缩尝试更短的窗口。
* 判断依据是「答案要求窗口尽量大还是尽量小」，而不是题目问最大值还是最小值：例如 209 求和的最小长度，属于最小窗口；3 求最长无重复子串，属于最大窗口。

## 6 例题

### 6.1 3. 无重复字符的最长子串

给定字符串 `s`，求不含重复字符的最长连续子串的长度。窗口内用 `count` 数组统计每个字符出现的次数，一旦某个字符出现次数大于 1 就收缩左边界。

```java
class Solution {
    public int lengthOfLongestSubstring(String s) {
        int[] count = new int[128]; // ASCII 字符集
        int left = 0, right = 0, res = 0;
        while (right < s.length()) {
            char c = s.charAt(right++);
            count[c]++;
            while (count[c] > 1) { // 窗口内出现重复
                count[s.charAt(left++)]--;
            }
            res = Math.max(res, right - left); // 收缩后一定合法
        }
        return res;
    }
}
```

### 6.2 209. 长度最小的子数组

给定正整数数组 `nums` 和目标值 `target`，求和大于等于 `target` 的最短连续子数组长度，不存在返回 0。因为全是正数，窗口和具有单调性。

```java
class Solution {
    public int minSubArrayLen(int target, int[] nums) {
        int left = 0, right = 0, sum = 0;
        int res = Integer.MAX_VALUE;
        while (right < nums.length) {
            sum += nums[right++];
            while (sum >= target) {           // 合法，先更新答案
                res = Math.min(res, right - left);
                sum -= nums[left++];          // 再收缩，尝试更短的窗口
            }
        }
        return res == Integer.MAX_VALUE ? 0 : res;
    }
}
```

### 6.3 76. 最小覆盖子串

给定字符串 `s` 和 `t`，求 `s` 中涵盖 `t` 全部字符（含重复次数）的最短子串，不存在返回空串。用 `need` 记录目标字符频次，`window` 记录窗口频次，`valid` 记录「已达标的字符种数」。

```java
class Solution {
    public String minWindow(String s, String t) {
        Map<Character, Integer> need = new HashMap<>();
        Map<Character, Integer> window = new HashMap<>();
        for (char c : t.toCharArray()) need.put(c, need.getOrDefault(c, 0) + 1);
        int left = 0, right = 0, valid = 0, start = 0, len = Integer.MAX_VALUE;
        while (right < s.length()) {
            char c = s.charAt(right++);
            if (need.containsKey(c)) {
                window.put(c, window.getOrDefault(c, 0) + 1);
                if (window.get(c).equals(need.get(c))) valid++; // 该字符达标
            }
            while (valid == need.size()) { // 已覆盖，先记录再收缩
                if (right - left < len) {
                    start = left;
                    len = right - left;
                }
                char d = s.charAt(left++);
                if (need.containsKey(d)) {
                    if (window.get(d).equals(need.get(d))) valid--; // 移出后不达标
                    window.put(d, window.get(d) - 1);
                }
            }
        }
        return len == Integer.MAX_VALUE ? "" : s.substring(start, start + len);
    }
}
```

### 6.4 567. 字符串的排列

判断 `s2` 是否包含 `s1` 的某个排列，等价于判断 `s2` 中是否存在长度为 `len(s1)`、字符频次与 `s1` 完全相同的窗口。这是固定窗口。

```java
class Solution {
    public boolean checkInclusion(String s1, String s2) {
        int[] need = new int[26];
        int[] window = new int[26];
        for (char c : s1.toCharArray()) need[c - 'a']++;
        int needCnt = 0; // s1 中不同字符的种数
        for (int i = 0; i < 26; i++) if (need[i] > 0) needCnt++;
        int left = 0, right = 0, valid = 0, k = s1.length();
        while (right < s2.length()) {
            int c = s2.charAt(right++) - 'a';
            if (need[c] > 0) {
                window[c]++;
                if (window[c] == need[c]) valid++;
            }
            while (right - left > k) { // 固定窗口：超出 k 就收缩
                int d = s2.charAt(left++) - 'a';
                if (need[d] > 0) {
                    if (window[d] == need[d]) valid--;
                    window[d]--;
                }
            }
            if (valid == needCnt) return true; // 长度≤k 且全部字符达标，必然等于 k
        }
        return false;
    }
}
```

### 6.5 239. 滑动窗口最大值

返回每个长度为 `k` 的窗口中的最大值。窗口滑动时最值无法用「和」那种增量方式维护，需要**单调队列**：队列存下标，对应的值从队首到队尾单调递减，队首就是当前窗口最大值。

```java
class Solution {
    public int[] maxSlidingWindow(int[] nums, int k) {
        int n = nums.length;
        int[] res = new int[n - k + 1];
        Deque<Integer> deque = new ArrayDeque<>(); // 存下标，值单调递减
        for (int right = 0; right < n; right++) {
            // 队尾比当前值小的都不可能成为最大值，直接弹掉
            while (!deque.isEmpty() && nums[deque.peekLast()] <= nums[right]) deque.pollLast();
            deque.offerLast(right);
            if (deque.peekFirst() <= right - k) deque.pollFirst(); // 队首已滑出窗口
            if (right >= k - 1) res[right - k + 1] = nums[deque.peekFirst()];
        }
        return res;
    }
}
```

## 7 复杂度分析

| 题目 | 时间复杂度 | 空间复杂度 | 说明 |
| --- | --- | --- | --- |
| 3. 无重复字符的最长子串 | O(n) | O(1) | 128 大小的定长计数数组 |
| 209. 长度最小的子数组 | O(n) | O(1) | 左右指针各走一遍 |
| 76. 最小覆盖子串 | O(n + m) | O(字符集) | n、m 分别为 s、t 长度 |
| 567. 字符串的排列 | O(n + m) | O(1) | 两个长度 26 的数组 |
| 239. 滑动窗口最大值 | O(n) | O(k) | 每个下标最多进出队各一次 |

* 时间 O(n) 的来源是「每个元素最多被加入窗口一次、移出窗口一次」，指针不会回退。
* 空间取决于统计量：计数数组是 O(字符集) 常数，哈希表是 O(不同字符数)，单调队列是 O(k)。
* 若每次收缩都用 `for` 重新统计窗口，复杂度会退化到 O(n*k)，这正是滑动窗口要避免的。

## 8 常见坑

* **收缩条件用 `while` 而不是 `if`**：一次右扩可能让窗口连续多次不合法，用 `if` 只收缩一步会漏掉情况。
* **窗口长度是 `right - left`**：模板里 `right` 已经自增过，不要再写成 `right - left + 1`，这是最常见的差一错误。
* **更新答案的时机**：最小窗口在收缩前更新，最大窗口在收缩后更新，写反了会得到偏大或偏小的结果。
* **字符计数数组的维护**：加入时 `count[c]++`、移出时 `count[d]--`，两者必须成对出现；`valid` 的加减要在计数变化前后判断一致，先判断后修改或先修改后判断必须全篇统一。
* **字符集大小**：只有 ASCII 用 128，只有小写字母用 26，含中文或其他字符时改用 `HashMap`，否则会数组越界。
* **`Integer` 比较**：`Map<Character, Integer>` 的计数比较用 `equals` 或 `intValue()`，用 `==` 在超过 127 时会出错。
* **边界**：`k > n`、`s` 为空、`t` 比 `s` 长等情况要先特判，避免 `new int[n - k + 1]` 出现负长度。
