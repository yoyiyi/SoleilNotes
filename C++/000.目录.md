## 2 三条学习路线

**路线 A：零基础入门（3~4 周）**

1. [C++基础](C++基础.md)：每天 2 章，所有示例自己编译一遍（`g++ -std=c++17 -Wall -Wextra demo.cpp`）。
2. [C++STL标准库](C++STL标准库.md)：边学边用 `vector`/`map`/`string`，把「容器怎么选」当成日常判断。
3. [C++详解](C++详解.md) 第 3、4、5 章（对象模型、构造析构、移动语义）——这是面试最容易被追问的部分。

**路线 B：面试冲刺（1~2 周）**

1. 先做 [C++面试题](C++面试题.md) 的 70 题，标出答不出的。
2. 按错题回查 [C++详解](C++详解.md) 与 [C++STL标准库](C++STL标准库.md) 的对应章节。
3. 并发相关一律回 [C++并发编程](C++并发编程.md)（尤其是条件变量、内存序、线程池）。
4. 用 [C与C++差异](../C/C与C++差异.md) 准备「C 和 C++ 你怎么看」这类开放题。

**路线 C：工程实战**

1. [C++项目实战](C++项目实战.md)：搭一个 CMake 项目，接 GoogleTest，跑一遍 Sanitizer。
2. [C++并发编程](C++并发编程.md) 第 7 章：把线程池自己写一遍，再用 TSan 验证没有数据竞争。
3. [C++详解](C++详解.md) 第 11、12 章：性能优化顺序与调试工具。

## 3 面试高频交叉点

- 对象生命周期：构造 → 使用 → 析构，与 RAII、智能指针、异常安全是同一件事的不同侧面。
- 多态的实现：虚函数表 → vptr → 对象布局，能和 C 的结构体布局对照着讲。
- 性能：`vector` 扩容、返回值优化（RVO/NRVO）、移动语义、`reserve`，本质都是「少拷贝」。
- 并发：`mutex` 解决互斥、`condition_variable` 解决等待、`atomic` 解决可见性与重排，三者不要混用。
- 常见追问：「为什么析构函数要 virtual」「`std::move` 到底做了什么」「`shared_ptr` 线程安全吗」「为什么模板定义要放头文件」。
