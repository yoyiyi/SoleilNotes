# 包管理机制和 PMS 目录

Android 包管理负责 APK 的解析、签名校验、安装/卸载、权限与组件查询，核心服务是 `PackageManagerService`（PMS）。

## 1 已完成

* [001 PackageManager 简介](001.PackageManager简介.md)：`PackageManager` 与 PMS 的关系、PMS 启动、APK 解析与 AXML、v1~v4 签名、安装流程、`Settings`/`packages.xml`、权限与查询 API。

## 2 计划覆盖

| 主题 | 计划内容 |
| --- | --- |
| PMS 启动 | `SystemServer` 引导阶段、`PackageManagerService.main()`、系统应用扫描与 `systemReady()` |
| APK 解析与签名校验 | `PackageParser`/`ParsingPackageUtils`、split APK、签名方案与 `apksigner` |
| 权限管理 | `PermissionManagerService`、运行时权限、`AppOps`、`PermissionController` |
| `PackageInstaller` | Session 生命周期、静默安装、`installd` 与 dexopt |
| 多用户与 `UserManager` | `UserManagerService`、per-user 数据目录、`UserHandle` 与安装隔离 |
