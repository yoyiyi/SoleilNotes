# LeetCode 高频题索引

本文按题型整理了 LeetCode 面试中出现频率最高的 79 道题（简单 23 道、中等 48 道、困难 8 道），每题给出一句话思路与时间复杂度，并在文末附上 8 道经典题的完整 Java 实现。题号与题名以 LeetCode 中文站为准，个别题目在不同版本中名称略有差异（例如「最大子数组和」曾用名「最大子序和」）。

**使用建议**

- 按题型刷，不要按题号顺序刷：同一专题连续做 3~5 道，才能把模板内化成手感。
- 每题先独立思考 15~20 分钟，写不出再看题解；看完必须关掉页面自己重写一遍。
- 面试前优先复习「简单 + 中等」中的高频题，困难题按目标公司和岗位取舍。
- 用「一句话思路」自测：能说清做法、边界和复杂度，才算真正掌握。
- 建一个错题本，记录卡住的原因（没想到、边界错、写得太慢），二刷只看错题。

## 一、数组与双指针

数组是面试的第一道门槛。双指针（对撞、快慢、滑动窗口）能把大部分 O(n²) 的暴力解优化到 O(n)，是性价比最高的套路。

| 题号 | 题目名 | 难度 | 一句话思路 | 时间复杂度 |
| --- | --- | --- | --- | --- |
| 1 | 两数之和 | 简单 | 哈希表存「值 → 下标」，遍历时查 target - x | O(n) |
| 11 | 盛最多水的容器 | 中等 | 双指针从两端收缩，每次移动较短的一侧 | O(n) |
| 15 | 三数之和 | 中等 | 排序后固定一个数，另外两个数用对撞双指针，注意去重 | O(n²) |
| 26 | 删除有序数组中的重复项 | 简单 | 快慢指针，慢指针指向最后一个已保留元素 | O(n) |
| 42 | 接雨水 | 困难 | 双指针维护左右最大高度，每次结算较矮的一侧 | O(n) |
| 48 | 旋转图像 | 中等 | 先沿主对角线转置，再左右翻转，原地完成 | O(n²) |
| 53 | 最大子数组和 | 中等 | dp[i] = max(nums[i], dp[i-1] + nums[i])，边遍历边更新 | O(n) |
| 56 | 合并区间 | 中等 | 按左端点排序，能合并就扩展右端点 | O(n log n) |
| 238 | 除自身以外数组的乘积 | 中等 | 先算前缀积，再从右往左累乘后缀积 | O(n) |
| 283 | 移动零 | 简单 | 快慢指针把非零元素前移，末尾统一补零 | O(n) |

**核心考点**：双指针的正确性来自「指针移动的单调性」——每次移动都必须能排除掉一批不可能成为答案的状态。写之前先想清楚：移动哪个指针、为什么可以移动、答案在哪里更新。

## 二、字符串

字符串题多与滑动窗口、双指针和模拟相关。Java 中要注意 `String` 不可变，频繁拼接用 `StringBuilder`；取字符用 `charAt`，不要反复 `toCharArray`。

| 14 | 最长公共前缀 | 简单 | 以第一个字符串为基准，逐列比较所有字符串 | O(n·m) |

**核心考点**：滑动窗口的模板是「右指针扩张、左指针收缩、在窗口满足条件时更新答案」。窗口内维护什么信息，决定了用哈希、计数数组还是单调队列。

## 四、栈与队列

单调栈解决「下一个更大/更小元素」，单调队列解决「滑动窗口最值」。两者都建议存下标而不是值，方便计算距离和处理重复元素。

| 题号 | 题目名 | 难度 | 一句话思路 | 时间复杂度 |
| --- | --- | --- | --- | --- |
| 20 | 有效的括号 | 简单 | 左括号入栈，右括号与栈顶匹配 | O(n) |
| 84 | 柱状图中最大的矩形 | 困难 | 单调递增栈，弹出时向两边扩展计算面积 | O(n) |
| 155 | 最小栈 | 中等 | 辅助栈同步保存当前最小值 | 每次操作 O(1) |
| 232 | 用栈实现队列 | 简单 | 入队栈 + 出队栈，出队栈空时整体倒灌 | 每次操作均摊 O(1) |
| 394 | 字符串解码 | 中等 | 栈保存重复次数和之前的字符串，遇到 ] 展开 | O(n) |
| 739 | 每日温度 | 中等 | 单调递减栈存下标，遇到更高温度时结算 | O(n) |

**核心考点**：单调栈的套路是「维护一个从栈底到栈顶单调的序列，新元素破坏单调性时不断弹栈并结算答案」。每个元素最多入栈、出栈一次，所以是线性的。

## 五、哈希

哈希把查找降到 O(1)，常见组合是「前缀和 + 哈希」「计数 + 哈希」「排序键 + 哈希」。面试中要先说清楚键是什么、值存什么。

| 题号 | 题目名 | 难度 | 一句话思路 | 时间复杂度 |
| --- | --- | --- | --- | --- |
| 49 | 字母异位词分组 | 中等 | 排序后的字符串（或字符计数）作为哈希键 | O(n·k log k) |
| 128 | 最长连续序列 | 中等 | 所有数入 Set，只从序列起点向后数 | O(n) |
| 169 | 多数元素 | 简单 | 哈希计数；最优解是摩尔投票 | O(n) |
| 242 | 有效的字母异位词 | 简单 | 字符计数数组比较，或排序后比较 | O(n) |
| 560 | 和为 K 的子数组 | 中等 | 前缀和 + 哈希表记录前缀和出现的次数 | O(n) |

**核心考点**：`560` 是「前缀和 + 哈希」的典型：遍历到 j 时，只要存在前缀和 `pre[j] - k`，就说明有一段子数组和为 k。注意 `pre[0] = 0` 要先放入哈希表。

## 六、二叉树

二叉树题的递归三问：终止条件是什么、左右子树返回什么、当前层要做什么。前序适合自顶向下传参，后序适合自底向上收集结果。

| 题号 | 题目名 | 难度 | 一句话思路 | 时间复杂度 |
| --- | --- | --- | --- | --- |
| 98 | 验证二叉搜索树 | 中等 | 中序遍历应严格递增，或递归传上下界 | O(n) |
| 101 | 对称二叉树 | 简单 | 递归比较左子树与右子树的镜像 | O(n) |
| 102 | 二叉树的层序遍历 | 中等 | BFS 按层出队，每轮记录当前层大小 | O(n) |
| 105 | 从前序与中序遍历序列构造二叉树 | 中等 | 前序定根，中序定左右区间，哈希定位根 | O(n) |
| 124 | 二叉树中的最大路径和 | 困难 | 后序递归返回单边最大贡献，全局更新答案 | O(n) |
| 226 | 翻转二叉树 | 简单 | 递归交换左右子树 | O(n) |
| 236 | 二叉树的最近公共祖先 | 中等 | 后序递归，左右子树各找到一个即为 LCA | O(n) |

**核心考点**：`124` 和 `543` 是同一类题——递归函数返回「能给父结点用的单边贡献」，而答案在「左贡献 + 右贡献 + 当前结点」处更新。分清「返回值」和「全局答案」是解题关键。

## 八、回溯

回溯 = 选择 + 递归 + 撤销选择。去重的前提是排序，然后用「同一层跳过相同元素」的规则；组合问题用 `start` 控制顺序，排列问题用 `visited` 标记使用情况。

| 题号 | 题目名 | 难度 | 一句话思路 | 时间复杂度 |
| --- | --- | --- | --- | --- |
| 17 | 电话号码的字母组合 | 中等 | 按数字逐位枚举字母，递归拼接 | O(4^n) |
| 22 | 括号生成 | 中等 | 保证左括号数不小于右括号数且都不超过 n | O(4^n / √n) |
| 39 | 组合总和 | 中等 | 排序后 DFS，可重复选当前数，超过 target 剪枝 | 指数级 |
| 46 | 全排列 | 中等 | 用 visited 标记，逐位填数 | O(n·n!) |
| 51 | N 皇后 | 困难 | 逐行放置，用列、主对角线、副对角线集合判重 | O(n!) |
| 78 | 子集 | 中等 | 每个元素选或不选，递归两种分支 | O(n·2^n) |

**核心考点**：画出一棵决策树，明确「每一层决定什么」。去重时先排序，再写 `if (i > start && nums[i] == nums[i-1]) continue;`，并想清楚这个判断为什么不会误伤同一树枝上的重复选择。

## 九、动态规划

先定义状态，再写转移，最后定边界和遍历顺序。空间优化前先确认「用到的旧值是否已被覆盖」，否则宁可多开一维。

| 题号 | 题目名 | 难度 | 一句话思路 | 时间复杂度 |
| --- | --- | --- | --- | --- |
| 62 | 不同路径 | 中等 | dp[i][j] = dp[i-1][j] + dp[i][j-1]，可滚动数组 | O(mn) |
| 70 | 爬楼梯 | 简单 | f(n) = f(n-1) + f(n-2)，用滚动变量 | O(n) |
| 72 | 编辑距离 | 困难 | 增删改三种转移取最小，注意空串初始化 | O(mn) |
| 121 | 买卖股票的最佳时机 | 简单 | 维护历史最低价，随时更新最大利润 | O(n) |
| 198 | 打家劫舍 | 中等 | dp[i] = max(dp[i-1], dp[i-2] + nums[i]) | O(n) |
| 300 | 最长递增子序列 | 中等 | 贪心 + 二分维护 tails 数组，或 O(n²) 朴素 DP | O(n log n) |
| 322 | 零钱兑换 | 中等 | 完全背包，dp[amount] 取硬币数最小值 | O(amount·n) |
| 416 | 分割等和子集 | 中等 | 转成 0-1 背包，判断能否恰好凑出 sum/2 | O(n·sum) |

**核心考点**：能识别出「背包」是关键。`322` 是完全背包（物品可重复选，容量正序遍历），`416` 是 0-1 背包（每个物品只能选一次，容量倒序遍历），遍历顺序写反会得到错误答案。

## 十、贪心

贪心需要证明「局部最优能推出全局最优」。区间问题常按左端点或右端点排序，再线性扫描；说不清证明时，优先考虑动态规划。

| 题号 | 题目名 | 难度 | 一句话思路 | 时间复杂度 |
| --- | --- | --- | --- | --- |
| 55 | 跳跃游戏 | 中等 | 维护当前能到达的最远下标，逐步更新 | O(n) |
| 122 | 买卖股票的最佳时机 II | 中等 | 贪心累加所有上涨区间的利润 | O(n) |
| 435 | 无重叠区间 | 中等 | 按右端点排序，优先保留结束早的区间 | O(n log n) |

## 十一、二分查找

二分的关键是循环不变量：明确区间是 `[left, right]` 还是 `[left, right)`，边界收缩才不容易错。求左边界和右边界要分别写，不要试图一个模板通吃。

| 题号 | 题目名 | 难度 | 一句话思路 | 时间复杂度 |
| --- | --- | --- | --- | --- |
| 33 | 搜索旋转排序数组 | 中等 | 判断哪一半有序，再决定收缩方向 | O(log n) |
| 34 | 在排序数组中查找元素的第一个和最后一个位置 | 中等 | 两次二分，分别找左边界和右边界 | O(log n) |
| 35 | 搜索插入位置 | 简单 | 二分查找第一个大于等于 target 的位置 | O(log n) |
| 69 | x 的平方根 | 简单 | 在 [0, x] 中二分，找最大的 mid 使 mid² ≤ x | O(log x) |

**核心考点**：写完二分后，用长度为 0、1、2 的数组各测一遍；再检查 `mid = left + (right - left) / 2` 是否可能死循环。`34` 是练习边界的最好题目。

## 十二、位运算

常见技巧：`n & (n - 1)` 消去最低位的 1，`n & -n` 取出最低位的 1，异或可以抵消成对出现的元素。位运算题代码短，但思路不容易现场想出来。

| 题号 | 题目名 | 难度 | 一句话思路 | 时间复杂度 |
| --- | --- | --- | --- | --- |
| 136 | 只出现一次的数字 | 简单 | 全部异或，成对出现的数互相抵消 | O(n) |
| 137 | 只出现一次的数字 II | 中等 | 统计每一位 1 的个数对 3 取余，或用状态机 | O(n) |

## 十三、堆与 TopK

求第 K 大用小根堆，求第 K 小用大根堆，堆里始终只保留 K 个候选。数据流的中位数用两个堆维持左右两半的平衡。

| 题号 | 题目名 | 难度 | 一句话思路 | 时间复杂度 |
| --- | --- | --- | --- | --- |
| 215 | 数组中的第K个最大元素 | 中等 | 维护大小为 K 的小根堆，堆顶即答案 | O(n log k) |
| 239 | 滑动窗口最大值 | 困难 | 单调递减双端队列存下标 | O(n) |
| 295 | 数据流的中位数 | 困难 | 大根堆存左半、小根堆存右半，保持平衡 | 每次操作 O(log n) |
| 347 | 前 K 个高频元素 | 中等 | 哈希计数 + 大小为 K 的小根堆 | O(n log k) |

**核心考点**：Java 的 `PriorityQueue` 默认是小根堆，大根堆要传 `(a, b) -> b - a`（注意溢出风险，稳妥写法是 `Comparator.reverseOrder()`）。`295` 要保证「大根堆元素个数等于小根堆，或比它多一个」，插入后调整。

### 206. 反转链表

难度：简单

**题目描述**：给定单链表的头结点 `head`，反转整个链表，并返回反转后的头结点。

**思路**：

- `prev` 指向已经反转部分的头结点，`cur` 指向当前待处理结点。
- 每一轮先保存 `cur.next`，否则修改指向后会丢失后继；再令 `cur.next = prev`。
- `prev` 与 `cur` 同步后移，`cur` 为空时，`prev` 就是新的头结点。

**复杂度**：时间 O(n)，空间 O(1)。

```java
class Solution {
    public ListNode reverseList(ListNode head) {
        ListNode prev = null; // 已反转部分的头结点
        ListNode cur = head;  // 当前待处理结点
        while (cur != null) {
            ListNode next = cur.next; // 先保存后继，避免断链
            cur.next = prev;          // 反转当前结点的指向
            prev = cur;               // prev 后移
            cur = next;               // cur 后移
        }
        return prev;
    }
}
```

### 15. 三数之和

难度：中等

**题目描述**：给定整数数组 `nums`，找出所有和为 0 且互不重复的三元组。

**思路**：

- 先排序，固定第一个数 `nums[i]`，问题转化为在剩余区间中找两数之和为 `-nums[i]`。
- 剩余区间用 `left`、`right` 对撞双指针，和偏小就右移 `left`，和偏大就左移 `right`。
- 找到一个答案后，左右指针都要跳过相邻的重复值；外层循环也要跳过重复的 `nums[i]`，否则结果会重复。
- 排序后若 `nums[i] > 0`，后面不可能再凑出 0，可以直接结束。

**复杂度**：时间 O(n²)，空间 O(1)（不计排序和结果集）。

```java
class Solution {
    public List<List<Integer>> threeSum(int[] nums) {
        List<List<Integer>> res = new ArrayList<>();
        Arrays.sort(nums); // 排序后双指针才有单调性
        for (int i = 0; i < nums.length - 2; i++) {
            if (nums[i] > 0) {
                break; // 最小的数都大于 0，后面不可能凑出 0
            }
            if (i > 0 && nums[i] == nums[i - 1]) {
                continue; // 跳过重复的第一个数
            }
            int left = i + 1;
            int right = nums.length - 1;
            while (left < right) {
                int sum = nums[i] + nums[left] + nums[right];
                if (sum == 0) {
                    res.add(Arrays.asList(nums[i], nums[left], nums[right]));
                    // 跳过重复的左右元素，避免产生重复三元组
                    while (left < right && nums[left] == nums[left + 1]) {
                        left++;
                    }
                    while (left < right && nums[right] == nums[right - 1]) {
                        right--;
                    }
                    left++;
                    right--;
                } else if (sum < 0) {
                    left++; // 和太小，左指针右移
                } else {
                    right--; // 和太大，右指针左移
                }
            }
        }
        return res;
    }
}
```

### 3. 无重复字符的最长子串

难度：中等

**题目描述**：给定字符串 `s`，找出其中不含重复字符的最长子串的长度。

**思路**：

- 维护一个窗口 `[left, right]`，保证窗口内没有重复字符。
- 哈希表记录每个字符最后出现的下标。右指针遇到字符 `c` 时，若 `c` 上一次出现的位置不小于 `left`，说明它还在窗口内，`left` 直接跳到 `last[c] + 1`。
- 每轮用 `right - left + 1` 更新答案。

**复杂度**：时间 O(n)，空间 O(Σ)，Σ 为字符集大小。

```java
class Solution {
    public int lengthOfLongestSubstring(String s) {
        Map<Character, Integer> last = new HashMap<>(); // 字符 -> 最后出现的下标
        int left = 0;
        int maxLen = 0;
        for (int right = 0; right < s.length(); right++) {
            char c = s.charAt(right);
            // 重复字符仍在窗口内，左边界跳到它后面一位
            if (last.containsKey(c) && last.get(c) >= left) {
                left = last.get(c) + 1;
            }
            last.put(c, right);
            maxLen = Math.max(maxLen, right - left + 1);
        }
        return maxLen;
    }
}
```

### 102. 二叉树的层序遍历

难度：中等

**题目描述**：按层返回二叉树每个结点的值，自顶向下，同一层从左到右。

**思路**：

- 用队列保存待访问的结点，先把根结点入队。
- 每一轮先记录当前队列大小 `size`，只弹出这 `size` 个结点，它们恰好构成一层。
- 弹出结点的同时，把非空的左右子结点入队，供下一层使用。

**复杂度**：时间 O(n)，空间 O(n)（队列最多保存一层的结点）。

```java
class Solution {
    public List<List<Integer>> levelOrder(TreeNode root) {
        List<List<Integer>> res = new ArrayList<>();
        if (root == null) {
            return res;
        }
        Deque<TreeNode> queue = new ArrayDeque<>();
        queue.offer(root);
        while (!queue.isEmpty()) {
            int size = queue.size(); // 当前层的结点数
            List<Integer> level = new ArrayList<>(size);
            for (int i = 0; i < size; i++) {
                TreeNode node = queue.poll();
                level.add(node.val);
                if (node.left != null) {
                    queue.offer(node.left);
                }
                if (node.right != null) {
                    queue.offer(node.right);
                }
            }
            res.add(level);
        }
        return res;
    }
}
```

### 300. 最长递增子序列

难度：中等

**题目描述**：给定整数数组 `nums`，求最长严格递增子序列的长度（子序列不要求连续）。

**思路**：

- `tails[k]` 表示长度为 `k + 1` 的递增子序列末尾元素的最小值，`tails` 天然单调递增。
- 遍历每个 `x`，在 `tails[0, len)` 中二分查找第一个大于等于 `x` 的位置 `pos`，用 `x` 替换它。
- 若 `pos == len`，说明 `x` 可以接在当前最长序列后面，长度加一。
- 最终 `len` 就是答案。该贪心替换不会破坏「长度相同的序列末尾尽可能小」这一性质。

**复杂度**：时间 O(n log n)，空间 O(n)。

```java
class Solution {
    public int lengthOfLIS(int[] nums) {
        int[] tails = new int[nums.length];
        int len = 0; // 当前最长递增子序列的长度
        for (int x : nums) {
            // 在 tails[0, len) 中找第一个大于等于 x 的位置
            int left = 0;
            int right = len;
            while (left < right) {
                int mid = left + (right - left) / 2;
                if (tails[mid] < x) {
                    left = mid + 1;
                } else {
                    right = mid;
                }
            }
            tails[left] = x; // 替换，让同长度的序列末尾更小
            if (left == len) {
                len++; // 说明 x 接在了最长序列后面
            }
        }
        return len;
    }
}
```

### 72. 编辑距离

难度：困难

**题目描述**：求把 `word1` 变成 `word2` 所需的最少操作数，每次可以插入、删除或替换一个字符。

**思路**：

- `dp[i][j]` 表示把 `word1` 的前 `i` 个字符变成 `word2` 的前 `j` 个字符所需的最少操作数。
- 边界：`dp[i][0] = i`（删除 i 次），`dp[0][j] = j`（插入 j 次）。
- 若末尾字符相同，直接继承 `dp[i-1][j-1]`；否则在替换、删除、插入三种操作中取最小，再加 1。
- 答案是 `dp[m][n]`，时间复杂度 O(mn)。

**复杂度**：时间 O(mn)，空间 O(mn)，可优化到 O(n)。

```java
class Solution {
    public int minDistance(String word1, String word2) {
        int m = word1.length();
        int n = word2.length();
        int[][] dp = new int[m + 1][n + 1];
        // 边界：其中一个串为空时，只能全部插入或删除
        for (int i = 0; i <= m; i++) {
            dp[i][0] = i;
        }
        for (int j = 0; j <= n; j++) {
            dp[0][j] = j;
        }
        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                if (word1.charAt(i - 1) == word2.charAt(j - 1)) {
                    dp[i][j] = dp[i - 1][j - 1]; // 末尾相同，不用操作
                } else {
                    // 分别是替换、删除、插入
                    dp[i][j] = 1 + Math.min(dp[i - 1][j - 1],
                            Math.min(dp[i - 1][j], dp[i][j - 1]));
                }
            }
        }
        return dp[m][n];
    }
}
```

### 215. 数组中的第K个最大元素

难度：中等

**题目描述**：给定整数数组 `nums` 和整数 `k`，返回数组中第 `k` 大的元素（按排序后的位置计，不是第 `k` 个不同的元素）。

**思路**：

- 维护一个大小为 `k` 的小根堆，堆里保存当前扫描到的最大的 `k` 个数。
- 新元素直接入堆；堆大小超过 `k` 时弹出堆顶，也就是这 `k` 个数里最小的那个。
- 遍历结束后，堆顶就是第 `k` 大。
- 如果面试官要求平均 O(n)，可以改用快速选择（partition 后只递归包含目标下标的一侧）。

**复杂度**：时间 O(n log k)，空间 O(k)。

```java
class Solution {
    public int findKthLargest(int[] nums, int k) {
        // Java 的 PriorityQueue 默认是小根堆
        PriorityQueue<Integer> heap = new PriorityQueue<>();
        for (int x : nums) {
            heap.offer(x);
            if (heap.size() > k) {
                heap.poll(); // 弹掉当前 k 个数中最小的
            }
        }
        return heap.peek(); // 堆顶就是第 k 大
    }
}
```

### 146. LRU 缓存

难度：中等

**题目描述**：设计并实现一个满足 LRU（最近最少使用）缓存约束的数据结构，支持 `get` 和 `put`，要求平均时间复杂度为 O(1)。

**思路**：

- 哈希表 `key -> Node` 实现 O(1) 定位，双向链表维护访问顺序：头部最新，尾部最旧。
- `get` 命中后，把该结点从原位置摘下并插入头部。
- `put` 时若 key 已存在，更新值并移到头部；若不存在，新建结点插入头部，容量满则删除尾部结点，同时从哈希表中移除。
- 使用头尾两个哨兵结点，可以省去大量空指针判断。

**复杂度**：`get`、`put` 均为 O(1)，空间 O(capacity)。

```java
class LRUCache {
    // 双向链表结点，同时保存 key，便于淘汰时同步删除哈希表
    private static class Node {
        int key;
        int value;
        Node prev;
        Node next;

        Node(int key, int value) {
            this.key = key;
            this.value = value;
        }
    }

    private final int capacity;
    private final Map<Integer, Node> cache = new HashMap<>();
    private final Node head = new Node(0, 0); // 哨兵：头部，最新访问
    private final Node tail = new Node(0, 0); // 哨兵：尾部，最久未访问

    public LRUCache(int capacity) {
        this.capacity = capacity;
        head.next = tail;
        tail.prev = head;
    }

    public int get(int key) {
        Node node = cache.get(key);
        if (node == null) {
            return -1;
        }
        moveToHead(node); // 访问后变为最新
        return node.value;
    }

    public void put(int key, int value) {
        Node node = cache.get(key);
        if (node != null) {
            node.value = value;
            moveToHead(node);
            return;
        }
        if (cache.size() == capacity) {
            Node last = tail.prev; // 最久未使用的结点
            remove(last);
            cache.remove(last.key);
        }
        node = new Node(key, value);
        cache.put(key, node);
        addToHead(node);
    }

    private void moveToHead(Node node) {
        remove(node);
        addToHead(node);
    }

    private void addToHead(Node node) {
        node.prev = head;
        node.next = head.next;
        head.next.prev = node;
        head.next = node;
    }

    private void remove(Node node) {
        node.prev.next = node.next;
        node.next.prev = node.prev;
    }
}
```
