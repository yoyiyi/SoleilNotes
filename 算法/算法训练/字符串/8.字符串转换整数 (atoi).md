## 1 题目描述

请你实现 `myAtoi(String s)`，把字符串转换成一个 32 位有符号整数（类似 C/C++ 的 `atoi`）。

算法要求：

1. 丢弃无用的前导空格。
2. 读取可选的正负号，确定结果符号；没有符号时默认为正。
3. 读取连续数字，直到遇到非数字字符或字符串末尾，其余字符忽略。
4. 把读到的数字转成整数；一个数字都没读到则结果为 0。
5. 结果超出 `[−2^31, 2^31 − 1]` 时截断到边界值。

**注意：** 空白字符只包括空格 `' '`；除前导空格外，不要删除字符串中的其他字符。

## 2 示例

```text
输入: "42"                输出: 42
输入: "   -42"            输出: -42
输入: "4193 with words"   输出: 4193
输入: "words and 987"     输出: 0
输入: "-91283472332"      输出: -2147483648（下溢，截断到 INT_MIN）
```

## 3 思路

逐字符扫描，四步：跳空格 → 读符号 → 读数字并累加 → 越界立即截断。用状态机看就是 `START → SIGN → NUMBER → END`，任何非法输入都直接进入 `END`。

| 状态 | 输入 | 动作 |
| --- | --- | --- |
| START | 空格 | 继续跳过 |
| START | `+` / `-` | 记录符号，进入 SIGN |
| START / SIGN | 数字 | 进入 NUMBER 并累加 |
| START / SIGN | 其他字符 | 返回 0 |
| NUMBER | 数字 | `num = num * 10 + d`，判溢出 |
| NUMBER | 其他字符 | 结束，返回当前结果 |

## 4 边界

* 空串或全空格：`""`、`"   "` → 0。
* 只有符号：`"+"`、`"-"` → 0（符号后没有数字）。
* 前导空格后是非法字符：`"  abc"` → 0。
* 数字后跟非法字符：`"123abc"` → 123，遇到非数字立即停止。
* 正溢出：`"2147483648"` → `2147483647`；负溢出：`"-2147483649"` → `-2147483648`。
* 前导零：`"000123"` → 123；`"-0"` → 0。

## 5 复杂度

时间 O(n)，空间 O(1)，只扫描一遍字符串。

## 6 代码

```java
class Solution {
    public int myAtoi(String s) {
        int i = 0, n = s.length(), sign = 1;
        while (i < n && s.charAt(i) == ' ') i++;                 // 1. 跳前导空格
        if (i < n && (s.charAt(i) == '+' || s.charAt(i) == '-')) {
            sign = s.charAt(i++) == '-' ? -1 : 1;                // 2. 读符号
        }
        long num = 0;
        while (i < n && s.charAt(i) >= '0' && s.charAt(i) <= '9') {
            num = num * 10 + (s.charAt(i++) - '0');              // 3. 累加
            if (sign == 1 && num > Integer.MAX_VALUE) return Integer.MAX_VALUE;
            if (sign == -1 && -num < Integer.MIN_VALUE) return Integer.MIN_VALUE;
        }
        return (int) (sign * num);                               // 4. 没数字时 num 为 0
    }
}
```

## 7 易错点

1. **只跳前导空格**：中间的空格是终止符，`"12 34"` 应返回 12，不能先 `replace(" ", "")` 再解析。
2. **符号只能有一个**：`"+-12"`、`"  +-12"` 都返回 0；读到符号后必须紧跟数字。
3. **用 `long` 承接累加**：`int` 在 `num * 10` 时已经溢出，再判边界就来不及了。
4. **负数下界单独判断**：`-2147483648` 是合法值，应写 `-num < Integer.MIN_VALUE`，不能把正负溢出都截断到 `MAX_VALUE`。
5. **用 ASCII 范围判断数字**：`Character.isDigit` 会接受 Unicode 数字，`c - '0'` 会算错，应写 `c >= '0' && c <= '9'`。
