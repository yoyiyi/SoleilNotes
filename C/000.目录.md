# C 与 Linux 学习路线

本目录收录 C 语言与 Linux 基础两块内容，面向**校招/社招的 C/C++ 后端、嵌入式、系统方向面试**，两篇都是「可自测」的结构：概念 + 可编译示例 + 文末面试问答。

## 2 建议的学习顺序

1. **先 C 后 Linux**：C 的第 2 章（编译链接）和第 7 章（指针与内存）是后面所有内容的地基。
2. **边看边跑**：C 代码用 `gcc -Wall -Wextra -g -std=c11 xxx.c` 编译，Linux 命令在虚拟机或 WSL 里敲一遍。
3. **最后刷问答**：两篇文末的问答（C 30 题、Linux 25 题）遮住答案自测，答不出的回到对应章节。
4. **串起来**：把 C 的「进程内存布局」和 Linux 的「进程管理 / `/proc`」对照着看，面试常问「一个进程的内存长什么样」。

## 3 面试高频交叉点

- 程序从源码到进程：预处理 → 编译 → 汇编 → 链接 → `execve` → 加载器映射段 → `main`。
- 内存：栈/堆/`.bss`/`.data`/`.rodata`/`.text`，与 Linux 的 `brk`/`mmap`、`/proc/<pid>/maps` 对应。
- 进程与线程：`fork` 的写时复制、僵尸进程、`wait`/`waitpid`。
- 性能排查：`top` 看 CPU、`free`/`vmstat` 看内存、`iostat` 看 IO、`lsof`/`ss` 看句柄与端口。
- 常见追问：「`malloc` 一定走系统调用吗」「为什么 `free` 之后指针要置 NULL」「软链接和硬链接的区别」「进程 D 状态是什么」。
