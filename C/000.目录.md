## 2 三条学习路线

**路线 A：零基础入门（约 2~3 周）**

1. [C基础](C基础.md)：每天 2 章，所有示例自己敲一遍。
2. [Linux基础](Linux基础.md)：配合虚拟机/WSL 操作一遍目录、权限、用户。
3. [Linux常用命令](Linux常用命令.md)：当成手册用，边用边记高频的 30 个。
4. [C详解](C详解.md) 第 2、4、5 章（编译链接、指针、内存）——这是后面所有内容的地基。

**路线 B：面试冲刺（约 1~2 周）**

1. 先做 [C面试题](C面试题.md) 与 [Linux面试题](Linux面试题.md)，把答不出的题目标出来。
2. 按错题回查 [C详解](C详解.md) / [Linux详解](Linux详解.md) 对应章节。
3. 用 [C标准库速查](C标准库速查.md) 过一遍「手写函数」与「标准库陷阱」。
4. 场景题重点看 [Linux性能排查](Linux性能排查.md) 第 10 章的五类故障。

**路线 C：工程实战（有项目时）**

1. [Linux Shell脚本](Linux Shell脚本.md)：把重复操作脚本化（日志清理、备份、健康检查）。
2. [Linux性能排查](Linux性能排查.md)：建立排障套路，线上下意识先看 load/内存/IO。
3. [C详解](C详解.md) 第 11 章：学会用 `-fsanitize=address` 与 gdb 定位内存问题。

## 3 面试高频交叉点

- 程序从源码到进程：预处理 → 编译 → 汇编 → 链接 → `execve` → 加载器映射段 → `main`。
- 内存：栈/堆/`.bss`/`.data`/`.rodata`/`.text`，与 Linux 的 `brk`/`mmap`、`/proc/<pid>/maps` 对应。
- 进程与线程：`fork` 的写时复制、僵尸进程、`wait`/`waitpid`。
- 性能排查：`top` 看 CPU、`free`/`vmstat` 看内存、`iostat` 看 IO、`lsof`/`ss` 看句柄与端口。
- 常见追问：「`malloc` 一定走系统调用吗」「为什么 `free` 之后指针要置 NULL」「软链接和硬链接的区别」「进程 D 状态是什么」。

## 4 还可以继续补的方向

- **C 项目实战**：Makefile/CMake 工程、静态库与动态库打包、单元测试（如 Unity/CMocka）。
- **Linux 网络编程**：socket API、TCP 三次握手在代码里的体现、epoll 与 Reactor、IO 多路复用对比。
- **Linux 内核与 eBPF**：`bpftrace`/`perf` 深入、内核模块与 tracepoint。
- **C++ 与 C 的差异**：RAII、智能指针、移动语义，可配合 [C++基础](../C++/C++基础.md) 一起看。
