## 2 三条学习路线

**路线 A：零基础入门（2~3 周）**

1. [C基础](C基础.md)：每天 2 章，示例自己敲一遍。
2. [Linux基础](Linux基础.md)：配合虚拟机/WSL 操作目录、权限、用户。
3. [Linux常用命令](Linux常用命令.md)：当手册用，先记高频 30 个。
4. [C详解](C详解.md) 第 2、4、5 章（编译链接、指针、内存）。

**路线 B：面试冲刺（1~2 周）**

1. 先做 [C面试题](C面试题.md) 与 [Linux面试题](Linux面试题.md)，标出错题。
2. 按错题回查 [C详解](C详解.md) / [Linux详解](Linux详解.md)。
3. 用 [C标准库速查](C标准库速查.md) 过「手写函数」与「标准库陷阱」；用 [C笔试手写题](C笔试手写题.md) 练手速。
4. 场景题看 [Linux性能排查](Linux性能排查.md) 第 10 章五类故障。

**路线 C：工程实战**

1. [C项目实战](C项目实战.md)：Makefile/CMake、库的打包、单元测试、gdb 定位。
2. [Linux Shell脚本](Linux%20Shell脚本.md)：把重复操作脚本化。
3. [Linux网络编程](Linux网络编程.md)：写一个 echo server + epoll 版本，理解连接与 IO 模型。
4. [Linux内核与eBPF](Linux内核与eBPF.md)：用 bpftrace 观察自己程序的 syscall 与耗时。

## 3 面试高频交叉点

- 程序从源码到进程：预处理 → 编译 → 汇编 → 链接 → `execve` → 加载器映射段 → `main`。
- 内存：栈/堆/`.bss`/`.data`/`.rodata`/`.text`，与 Linux 的 `brk`/`mmap`、`/proc/<pid>/maps` 对应。
- 进程与线程：`fork` 的写时复制、僵尸进程、`wait`/`waitpid`。
- 网络：`socket` 是文件描述符，`epoll` 管理的是 fd 就绪事件，粘包属于应用层协议问题。
- 性能排查：`top` 看 CPU、`free`/`vmstat` 看内存、`iostat` 看 IO、`lsof`/`ss` 看句柄与端口。
- 常见追问：「`malloc` 一定走系统调用吗」「`free` 之后为什么置 NULL」「软链接和硬链接的区别」「进程 D 状态是什么」「epoll 为什么快」。
