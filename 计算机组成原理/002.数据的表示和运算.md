## 1 数据的表示概述

计算机内部所有信息（数值、字符、指令）都用二进制 0/1 编码。先区分两个术语：

* **真值**：机器数真正代表的数值，带正负号，如 -1011B。
* **机器数**：符号位与数值位一起编码后的二进制串，符号位 0 正、1 负。

| 类别 | 小数点位置 | 常用编码 | 说明 |
| --- | --- | --- | --- |
| 定点数 | 固定 | 原码、反码、补码、移码 | 硬件简单、速度快 |
| 浮点数 | 浮动 | IEEE 754 | 阶码 + 尾数，范围大、精度可调 |

### 1.1 进位计数制

* 基数 R：该进制允许使用的数字个数，R 进制数字取 0 ~ R-1。
* 位权：整数部分第 i 位的权为 R^i，小数部分第 i 位的权为 R^(-i)。

任意 R 进制数按权展开：`N = Σ d(i) × R^i`。常用进制的书写方式：

书写时常用后缀区分进制：二进制 1011B、八进制 173O、十进制 123D、十六进制 2BH（也常写成 0b1011、0o173、0x2B）。

### 1.2 进制转换

1. 二进制 ↔ 八进制：以小数点为界，向左向右每 **3 位**一组，不足补 0。
2. 二进制 ↔ 十六进制：每 **4 位**一组，不足补 0。
3. 十进制 → R 进制：整数「除 R 取余、逆序排列」，小数「乘 R 取整、顺序排列」。
4. R 进制 → 十进制：按权展开求和。

**例 1** 将十进制 43.6875 转换为二进制和十六进制。

```text
整数部分：43÷2=21余1, 21÷2=10余1, 10÷2=5余0, 5÷2=2余1, 2÷2=1余0, 1÷2=0余1
          逆序读取得 101011
小数部分：0.6875×2=1.375取1, 0.375×2=0.75取0, 0.75×2=1.5取1, 0.5×2=1.0取1
          顺序读取得 .1011
所以 43.6875 = 101011.1011B = 0010 1011.1011B = 2B.BH
校验：2×16 + 11 + 11/16 = 43.6875 ✔
```

## 2 定点数的编码表示

### 2.1 原码、反码、补码、移码

设机器字长为 n+1 位（1 位符号位 + n 位数值位），以定点整数为例：

| 编码 | 定义 | 0 的表示 | 特点 |
| --- | --- | --- | --- |
| 原码 | 符号位 + 绝对值 | 有两种（+0、-0） | 直观，但加减要判符号，硬件复杂 |
| 反码 | 正数同原码；负数符号位不变、数值位取反 | 有两种 | 过渡编码，很少单独使用 |
| 补码 | 正数同原码；负数 = 反码末位加 1 | 唯一 | 减法变加法，0 唯一，最常用 |
| 移码 | 补码符号位取反（即真值加 2^n） | 唯一 | 大小顺序同无符号数，只用于阶码 |

补码的快速求法：从右往左找到**第一个 1**（连同该位保留），它左边的所有位（含符号位）全部取反。

**例 2** 求 -45 的四种机器数（8 位）：45 = 0010 1101，故原码 1010 1101、反码 1101 0010、补码 1101 0011、移码 0101 0011（验证：-45 + 128 = 83 = 0101 0011）。

由补码求真值：符号位为 1 时，真值 = -(各位取反后加 1)。如 1110 0110 → 取反 0001 1001 → 加 1 得 0001 1010 = 26 → 真值 -26。

### 2.2 表示范围

| 编码 | 定点整数 | 定点小数 | 可表示个数 |
| --- | --- | --- | --- |
| 原码 | -(2^n - 1) ~ +(2^n - 1) | -(1 - 2^(-n)) ~ +(1 - 2^(-n)) | 2^(n+1) - 1 |
| 反码 | -(2^n - 1) ~ +(2^n - 1) | -(1 - 2^(-n)) ~ +(1 - 2^(-n)) | 2^(n+1) - 1 |
| 补码 | -2^n ~ +(2^n - 1) | -1 ~ +(1 - 2^(-n)) | 2^(n+1) |
| 移码 | -2^n ~ +(2^n - 1) | -1 ~ +(1 - 2^(-n)) | 2^(n+1) |

8 位整数时：原码、反码为 -127 ~ +127，补码、移码为 -128 ~ +127。必须记住的结论：

* 补码比原码多表示一个负数（整数 -2^n、小数 -1），因为 0 只有一种编码；补码的补码等于原码，符号位可直接参加运算。
* 移码与补码只差符号位取反，**数值位完全相同**；移码全 0 最小、全 1 最大，可按无符号数比较大小。
* 同一二进制串在不同编码下真值不同，答题必须标明编码。

## 3 补码的加减运算与溢出判断

### 3.1 运算公式

在模 2^(n+1) 意义下：

```text
[x + y]补 = [x]补 + [y]补      （符号位一起参加运算，丢弃符号位向上的进位）
[x - y]补 = [x]补 + [-y]补
[-y]补 = [y]补 连同符号位全部取反、末位加 1
```

补码把减法变成加法，运算器只需一个加法器，这是它成为主流编码的根本原因。

### 3.2 溢出判断

溢出指结果超出可表示范围。**只有同号相加（或同号相减）才可能溢出**，且溢出时结果符号必然错误：两正相加得负、两负相加得正都是溢出。

| 方法 | 判据 | 说明 |
| --- | --- | --- |
| 双符号位（变形补码） | 00 正常正、11 正常负、01 正溢出、10 负溢出 | 最高符号位是真符号，第二位判溢出，最常用 |
| 单符号位进位 | C(s) ⊕ C(1) = 1 则溢出 | C(s) 为符号位进位，C(1) 为最高数值位进位 |
| 操作数与结果符号 | 两数同号而结果异号则溢出 | 减法先转成加法再判断 |

### 3.3 例题：105 + 58 与 -105 - 58（8 位补码）

```text
① 105 + 58 = 163 > 127，应溢出
   0110 1001 + 0011 1010 = 1010 0011（符号为 1）→ 与「正+正」不符，正溢出
   双符号位：00 1101001 + 00 0111010 = 01 0100011 → 01 正溢出 ✔
② -105 - 58 = -163 < -128，应溢出；[-105]补 = 1001 0111，[-58]补 = 1100 0110
   1001 0111 + 1100 0110 = 1 0101 1101 → 丢弃进位得 0101 1101（+93），负溢出
   双符号位：11 0010111 + 11 1000110 = 110 1011101 → 舍最高位得 10 1011101，负溢出 ✔
```

### 3.4 算术移位与逻辑移位

* 逻辑移位：左移右移空位一律补 0，符号位也参与移动，用于无符号数。
* 算术移位：符号位不动。原码左右移都补 0；反码左移补 0、右移补 1；补码左移补 0、右移补符号位。补码算术右移相当于除以 2 后向下取整（-4 右移一位得 -2，-3 右移一位仍是 -2）。
* 移位后若符号位与最高数值位不一致，说明发生了溢出。

## 4 定点乘法与除法

### 4.1 原码一位乘

思路是「符号单独处理、绝对值相乘」：乘积符号 = 两符号位异或；硬件用 ACC 存部分积（n+1 位）、MQ 存乘数兼乘积低位；每步看 MQ 最低位，为 1 则 ACC 加 |x|，随后 (ACC, MQ) 整体**逻辑右移**；共 n 次。

**例 3** 计算 1101 × 1011（即 13 × 11 = 143）。

```text
初始：ACC = 0 0000，MQ = 1011，X = 1101
次数  MQ最低位  操作               ACC     MQ
 1       1      ACC+X = 01101     00110   1101   （右移）
 2       1      ACC+X = 10011     01001   1110   （右移）
 3       0      不加              00100   1111   （右移）
 4       1      ACC+X = 10001     01000   1111   （右移）

乘积 = ACC 低 4 位 + MQ = 1000 1111B = 143 ✔
```

### 4.2 补码一位乘（Booth 乘法）

把乘数 y 按补码展开，用相邻两位的差值决定这一步加还是减：

`y = -y(n-1)·2^(n-1) + Σ y(i)·2^i = Σ (y(i-1) - y(i))·2^i`，约定 y(-1) = 0。
第 i 步的乘数位 d(i) = y(i-1) - y(i) 只可能取 -1、0、+1，于是只需看相邻两位：

| y(i) y(i-1) | d(i) | 操作 |
| --- | --- | --- |
| 0 0 | 0 | 部分积不变 |
| 0 1 | +1 | 部分积加 [x]补 |
| 1 0 | -1 | 部分积减 [x]补（即加 [-x]补） |
| 1 1 | 0 | 部分积不变 |

要点：符号位与数值位一起运算、**不需要专门处理符号**；每步后把 (ACC, MQ, Q(-1)) 作为整体做**算术右移**；乘数 n 位就做 n 次「判断 + 移位」，最后一步不移位。

**例 4** 用 Booth 算法计算 (-3) × 6（4 位补码）。

```text
[x]补 = 1101，[-x]补 = 0011，[y]补 = 0110
A 取 5 位（符号扩展）：M = 1 1101，-M = 0 0011
初始：A = 0 0000，Q = 0110，Q(-1) = 0

次数  Q0 Q(-1)  操作                     A        Q      Q(-1)
 1     0  0     不加；算术右移          0 0000   0011   0
 2     1  0     A+(-M) = 00011 后右移   0 0001   1001   1
 3     1  1     不加；算术右移          0 0000   1100   1
 4     0  1     A+M = 11101 后右移      1 1110   1110   0

结果 = A,Q 取低 8 位 = 1110 1110 = -18 = (-3) × 6 ✔
```

### 4.3 原码除法

* **恢复余数法**：先减除数，余数为负说明不够减，商上 0 并加回除数（恢复余数）再左移；余数为正商上 1。步数不固定。
* **加减交替法（不恢复余数法）**：余数为正商 1，下一步左移后减 y；余数为负商 0，下一步左移后加 y，省去恢复操作；最后一步余数为负仍需加 y 恢复。

以 7 ÷ 3 为例：ACC 存余数、MQ 存被除数兼商、X 存除数，每步先左移再算 ACC - X，四步商依次为 0、0、1、0，最终商 0010 = 2、余数 0001 = 1。高速场合可用阵列乘法器（如 Wallace 树）把部分积并行压缩，用硬件换时间。

## 5 浮点数的表示与 IEEE 754

### 5.1 浮点数的一般格式

`N = M × R^E`：M 为尾数（决定精度），E 为阶码（决定范围），R 为阶的基数（通常为 2）。

* 阶码用**移码**表示，便于比较大小；尾数常用原码，规格化成 1.xxxx 或 0.1xxxx。
* 规格化保证尾数最高位是有效数字；表示范围由阶码位数决定，精度由尾数位数决定。

### 5.2 IEEE 754 标准

| 参数 | 单精度（float） | 双精度（double） |
| --- | --- | --- |
| 总位数 | 32 | 64 |
| 符号位 S / 阶码 E / 尾数 M | 1 / 8 / 23 | 1 / 11 / 52 |
| 偏置值 bias | 127 | 1023 |
| 实际阶码 e | E - 127 | E - 1023 |
| 隐含位 | 1.M（规格化数） | 1.M（规格化数） |
| 最大正数 | (2 - 2^(-23)) × 2^127 ≈ 3.4 × 10^38 | (2 - 2^(-52)) × 2^1023 |
| 最小正规格化数 | 1.0 × 2^(-126) | 1.0 × 2^(-1022) |

机器数布局从左到右为 `S | E | M`，真值为 `(-1)^S × 1.M × 2^(E - bias)`。

### 5.3 例题：十进制与浮点机器数互转

**例 5** 求 -12.5 的 IEEE 754 单精度机器数；**例 6** 求单精度机器数 0x41C80000 的真值。

```text
例 5：① 12.5 = 1100.1 = 1.1001 × 2^3，故 e = 3
      ② 阶码 E = 3 + 127 = 130 = 1000 0010
      ③ 尾数取小数点后 1001，补 0 至 23 位 → 1001 0000 0000 0000 0000 000
      ④ 拼接 1 | 10000010 | 10010000000000000000000 = 0xC1480000

例 6：① 展开 0100 0001 1100 1000 0000 0000 0000 0000
      ② S = 0，E = 1000 0011 = 131，M = 1001 000...
      ③ e = 131 - 127 = 4，真值 = +1.1001 × 2^4 = 11001.0B = 25.0
```

### 5.4 特殊数值

| 阶码 E | 尾数 M | 含义 |
| --- | --- | --- |
| 全 0 | 全 0 | ±0（+0 与 -0 编码不同，数值相等） |
| 全 0 | 非 0 | 非规格化数，真值 = ±0.M × 2^(-126) |
| 全 1 | 全 0 | ±∞ |
| 全 1 | 非 0 | NaN（非数，如 0/0、∞ - ∞） |

非规格化数的作用是「渐进下溢」，最小正数可延伸到 2^(-149)，避免突然变为 0。

## 6 浮点数的加减运算

### 6.1 运算步骤

1. **对阶**：求阶差 ΔE，**小阶向大阶看齐**（小阶尾数右移 ΔE 位、阶码加 ΔE）。右移只丢低位、不丢最高有效位，故只能小向大。
2. **尾数加减**：对阶后按定点补码加减法运算。
3. **规格化**：左规（尾数每左移一位、阶码减一，可多次，用于 00.0xxx 型结果）；右规（尾数右移一位、阶码加一，**最多一次**，用于尾数绝对值 ≥ 1、双符号位为 01/10 时）。
4. **舍入与判溢出**：对阶或右规丢位后按「0 舍 1 入」「恒置 1 法」舍入，IEEE 754 默认就近舍入到偶数；只有阶码溢出才是真溢出（上溢/下溢），尾数溢出可用右规解决。

### 6.2 例题

设阶码 3 位补码（含 1 位符号位）、尾数 7 位补码（含 2 位符号位、5 位数值位），
x = 2^(-2) × (-0.1101)，y = 2^(-1) × 0.1011，求 x + y。

```text
① 机器数（尾数用双符号位补码）
   x：阶码 110（-2），尾数 11.10011（-0.11010 的补码）
   y：阶码 111（-1），尾数 00.10110
② 对阶：ΔE = (-2) - (-1) = -1，x 阶小
   x 尾数先补足 5 位得 11.00110，算术右移 1 位得 11.10011（即 -0.01101），阶码 110 加 1 得 111
③ 尾数相加
     11.10011（-0.01101）
   + 00.10110（+0.10110）
   -----------
    100.01001 → 丢弃符号位进位得 00.01001
④ 规格化：最高数值位与符号位相同，左规 1 位 → 00.10010，阶码 110
⑤ 结果：x + y = 2^(-2) × 0.10010
   验算：-0.203125 + 0.34375 = 0.140625 = 0.25 × 0.5625 ✔
```

要点：是否需要左规要看**相加之后**的尾数形式；左规可多次、右规最多一次；左规后阶码减、右规后阶码加。

## 7 C 语言中的类型转换与溢出

### 7.1 隐式转换

* 整型提升：`char`、`short`、位域先提升为 `int`（或 `unsigned int`）再运算；随后按等级向高者看齐：`int → unsigned int → long → unsigned long → long long → float → double`。

### 7.2 有符号与无符号、扩展与截断

* 同长度互转时**位模式不变**，只是解释方式变了：负数转无符号得 2^n - |x|，无符号高位为 1 时转有符号得负数。
* 有符号与无符号混合运算，有符号数先转无符号数，这是很多「反直觉」Bug 的来源。
* 短 → 长：有符号做**符号扩展**（高位补符号位），无符号做**零扩展**（补 0）。长 → 短：直接**截断**高位。

```c
int      a = -1;  unsigned b = a;   /* b = 4294967295，位模式 0xFFFFFFFF */
if (-1 < 1U) { /* 条件为假：-1 被转成 4294967295 */ }
short          s  = -1;           /* 0xFFFF */
unsigned short us = s;            /* 65535，位模式不变 */
long           l  = s;            /* -1，符号扩展 */
int  i = 128;  char c = (char)i;  /* char 有符号时 c = -128，高位被截断 */
unsigned u = 3000000000u;  int j = (int)u;  /* j = -1294967296，位模式不变 */
```

### 7.3 溢出

| 类型 | 溢出后的行为 |
| --- | --- |
| 无符号数 | 按模 2^n 回绕，行为由标准明确定义 |
| 有符号数 | C 标准规定为未定义行为，多数机器按补码回绕，但不能依赖 |
| 浮点 → 整数 | 超范围是未定义行为；正常时向零取整（-3.9 → -3） |

```c
unsigned char a = 200, b = 100;
unsigned char c = a + b;          /* 整型提升得 300，赋回 unsigned char 时 300 mod 256 = 44 */
int m = 2147483647;  m = m + 1;   /* 有符号溢出，通常得 -2147483648，但属于 UB */
float f = 1e20f;  int k = (int)f; /* 超出 int 范围，未定义行为 */
```

## 8 常考题型小结

* 进制转换：小数用「乘 2 取整」，注意位数与舍入；二、八、十六进制互转用 3 位 / 4 位分组。
* 编码与范围：给真值求四种码或由补码求真值；由位数推范围或由范围推最少位数，注意「-128 没有原码」这类陷阱。
* 补码加减：先转补码再相加，用双符号位判溢出并写明正溢 / 负溢。
* 乘法：原码一位乘「符号单独处理、部分积右移」；Booth「看相邻两位、符号位参加运算、最后一步不移位」。
* IEEE 754：十进制 ↔ 机器数互转，注意规格化、偏置值 127/1023、隐含的 1；能识别 0、非规格化数、∞、NaN。
* 浮点加减：对阶（小向大）→ 尾数加减 → 规格化（左规可多次、右规最多一次）→ 舍入 → 判溢出，顺序不能乱。
* C 语言：位模式不变、符号扩展 / 零扩展、截断、有符号与无符号混用、有符号溢出属 UB。
